## 1. 模块定位

火象专栏是首页主内容流，承载金融教育、市场分析、平台动态等内容文章。3.0 中火象专栏作为首页主要内容消费区域，目的：

1. **提升停留时长**：让用户在 App 内消费内容，增强粘性
2. **传递金融教育价值**：通过专业内容支撑产品定位
3. **运营触达**：作为运营内容的展示位

**核心约束**：

- 仅展示**官方运营在后台手动发布的内容**，不支持用户 UGC
- V1 移除了 2.0 版本的关注 / 取关、评论、举报功能
- 仅保留浏览量、点赞、分享 3 个互动功能

## 3. 文章列表（瀑布流）

### 3.1 列表布局

| 项 | 规则 |
|---|---|
| 布局类型 | 单列纵向列表（非传统瀑布流的双列）|
| 卡片间距 | 上下 12px |
| 左右边距 | 16px（页面边距）|
| 列表底部 | 加载更多 / 已加载完毕提示 |

### 3.2 文章卡片字段

每张卡片包含以下元素：

| 字段 | 说明 |
|---|---|
| 作者头像 | 圆形，尺寸 40px |
| 作者名称 | 官号名称，14px Medium |
| V 认证标识 | 官号必须有 V 标，置于头像右下角 |
| 发布时间 | 14px Regular，按时间显示规则展示（详见 3.3）|
| 置顶标签 | 仅置顶文章显示，红色 "置顶" 标签 |
| 文章标题 | 16px Semibold，最多 2 行，超出省略号 |
| 文章摘要 | 14px Regular，最多 2 行，超出省略号 |
| 文章配图 | 可选，运营在后台决定是否配图 |
| 浏览量 | 含图标"眼睛 + 数字"，使用 12px |
| 点赞数 | 含图标"点赞 + 数字"，使用 12px |
| 分享数 | 不展示分享数，仅展示分享按钮 |

**图片位的处理**：

- **有图片**：图片右侧布局，宽度约 96px，圆角 8px
- **无图片**：标题 + 摘要占满卡片宽度，无图片位

### 3.3 时间显示规则

| 时间区间 | 展示方式 |
|---|---|
| 1 分钟内 | 刚刚 |
| 1 分钟 ~ 1 小时 | X 分钟前 |
| 1 小时 ~ 24 小时 | X 小时前 |
| 昨天 | 昨天 |
| 7 天内（非昨天）| 前天 / X 天前 |
| 7 天前 ~ 当年 | MM-DD |
| 跨年 | YYYY-MM-DD |

### 3.4 排序规则

火象专栏文章排序逻辑：

1. **置顶文章在最上方**：运营在后台可配置 3-5 个置顶文章
2. **置顶文章之间按运营配置的优先级排序**
3. **非置顶文章按发布时间倒序**

**排序示例**：

```
[置顶 1] 火薪人才培养计划正式开启       ← 运营置顶
[置顶 2] 火薪人才培养计划——使用攻略    ← 运营置顶
[非置顶] 提名受阻、调查未决，美联储...  ← 时间最新
[非置顶] 美股本周关注的关键事件         ← 时间次新
[非置顶] 量化交易入门系列（一）         ← 时间较旧
```

V1 **不做算法推荐排序**，所有用户看到相同的排序结果。

### 3.5 加载规则

| 项 | 规则 |
|---|---|
| 默认加载 | 首屏 10 条 |
| 上拉加载 | 每次加载 10 条 |
| 下拉刷新 | 重新拉取最新文章列表（同时刷新置顶 + 非置顶）|
| 加载完毕 | 列表底部显示"已经到底啦" |

### 3.6 多个官号的展示

- 不同官号的文章**混排展示**，不区分官号分组
- 官号信息（头像、名称、V 标）展示在每张卡片顶部
- 用户**不能筛选**仅看某个官号的文章（V1 不支持）

## 4. 文章交互

### 4.1 点击文章卡片

- 跳转 [文章详情页](./03-文章详情页.md)
- 跳转时浏览量 +1（仅记录"打开详情页"，不区分用户停留时长）

### 4.2 浏览量

| 项 | 规则 |
|---|---|
| 计算规则 | 用户每打开一次文章详情页计 +1（不去重）|
| 显示规则 | < 1 万：显示具体数字（如"823"）<br>≥ 1 万：显示"1.2 万""3.5 万" |

### 4.3 点赞

V1 的点赞按钮**仅在文章详情页内**触发，列表卡片仅展示数字、不可点赞。

详见 [03-文章详情页](./03-文章详情页.md) 第 5.2 节。

### 4.4 分享

V1 的分享按钮**仅在文章详情页内**触发，列表卡片不展示分享按钮。

详见 [03-文章详情页](./03-文章详情页.md) 第 5.3 节。

### 4.5 已读 / 未读区分

V1 **不区分已读未读**，用户点击过的文章在列表中不会有视觉差异。

## 6. 异常态

| 异常 | 表现 | 处理 |
|---|---|---|
| 接口加载失败 | 列表为空 | 显示"加载失败，下拉刷新重试" |
| 上拉加载失败 | 列表底部 | 显示"加载失败，点击重试" |
| 文章被运营下线 | 用户在列表点击文章 | 详情页提示"文章已下线" |
| 文章配图加载失败 | 图片位置 | 占位图灰色背景 |
| 网络不可用 | 整体加载失败 | 显示网络异常提示 + 下拉刷新引导 |

## 8. 接口约束

| 能力 | 说明 |
|---|---|
| 拉取文章列表 | 分页拉取，按"置顶 + 时间倒序"返回 |

## 9. 后台配置说明

火象专栏的内容管理由运营后台完成，详见 [98-03-火象专栏管理（待输出）]。

后台配置至少支持：

- 创建 / 编辑 / 下线文章
- 设置 / 取消置顶（限制最多 3-5 篇置顶）
- 调整置顶之间的优先级
- 多个官号管理（创建官号、设置官号头像、V 标）
- 文章预览功能

## 10. V1 范围限制

明确**不在 V1 范围**的功能：

| 功能 | 说明 |
|---|---|
| 关注 / 取关官号 | 不支持 |
| 评论 | 不支持 |
| 举报 | 不支持 |
| 收藏文章 | 不支持 |
| 算法推荐 | 不支持，所有用户看到相同排序 |
| 按官号筛选 | 不支持 |
| 搜索文章 | 不支持（首页顶部无搜索框）|
| 文章分类 / 标签 | 不支持 |
| 已读未读区分 | 不支持 |
