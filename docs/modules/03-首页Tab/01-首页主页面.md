## 1. 页面定位

首页是用户每次打开 App 后看到的默认页面，承担四项职责：

1. **品牌曝光**：通过页面标题"火象社区"和视觉风格强化品牌印象
2. **运营触达**：通过运营 banner 推广活动、课程、新功能
3. **状态汇总**：通过等级简卡、评分简卡、实训账户简卡让用户快速了解自身状态
4. **内容消费**：通过火象专栏让用户消费金融教育内容，提升停留时长

首页定位为"流量入口 + 内容消费"，不是核心业务页面（核心业务在训练 Tab）。

## 3. 页面结构

### 3.1 整体布局

页面采用**纵向滚动**布局，从上到下依次：

| 顺序 | 区域 |
|---|---|
| 1 | 顶部导航栏 |
| 2 | 运营 Banner（轮播）|
| 3 | 等级简卡 + 评分简卡（左右并列） |
| 4 | 实训账户简卡 |
| 5 | 快捷入口 |
| 6 | 火象专栏标题（向下滚动时吸顶） |
| 7 | 火象专栏瀑布流 |

### 3.2 顶部导航栏

| 元素 | 内容 |
|---|---|
| 左侧 | 火象 LOGO + 标题"火象社区" |
| 右侧 | 消息图标（仅消息图标，无搜索 / 其他图标）|

**消息图标的角标**：

| 状态 | 显示 |
|---|---|
| 无未读消息 | 仅图标，无角标 |
| 1-99 条未读 | 图标右上角红色角标显示具体数字 |
| 99+ 条未读 | 图标右上角显示"99+" |

角标显示规则严格遵循[消息中心](../02-跨Tab通用/01-消息中心.md)模块。

### 3.3 运营 Banner

由运营在后台配置，详见 [98-02-首页 banner 配置（待输出）]。

| 项 | 规则 |
|---|---|
| 数量 | 最多 5 张（运营配置）|
| 自动播放 | 4 秒切换一张 |
| 指示器 | 底部小圆点指示器，区分当前页与其他页 |
| 滑动 | 支持左右手势滑动切换 |
| 点击行为 | 跳转 banner 配置的目标（活动 / 课程 / H5 / 不跳转）|

**无 banner 配置时**：整体隐藏 banner 区域，下方内容上移。

**单张 banner**：不展示指示器，不自动轮播。

### 3.4 等级简卡与评分简卡（左右并列）

等级简卡与评分简卡左右并列展示，**等级简卡占主要视觉权重**。

| 简卡 | 宽度占比 |
|---|---|
| 等级简卡 | 60% |
| 评分简卡 | 40% |

#### 3.4.1 等级简卡

| 区域 | 内容 |
|---|---|
| 第一行 | 等级标签"Lv X"（如 "Lv 3"）+ 右侧箭头 |
| 第二行 | XP 进度条 + 当前 XP / 下一级阈值（如 "230 / 630"）|
| 提示文字 | 距离下一级 XP 用文字提示：如"距离下一级还需 400 XP" |

**已达最高级（Lv 7）特殊处理**：

- 第二行显示"已达最高等级"，无进度条
- 卡片视觉可保持一致

**点击行为**：跳转等级详情页（待输出）。

**游客态**：

- 卡片显示"登录后查看你的成长"
- 点击触发[登录弹窗](../01-账号生命周期/03-登录弹窗.md)

#### 3.4.2 评分简卡

| 区域 | 内容 |
|---|---|
| 第一行 | 当周评分（数字，如 "38"）|
| 第二行 | 当周评级（字母，如 "D"）|

**点击行为**：跳转评分详情页（详细规则与计算逻辑见独立模块文档，待补）。

**评分规则**：详见独立"评分体系"模块文档（待补）。

**游客态**：

- 卡片显示"登录后查看你的评分"
- 点击触发[登录弹窗](../01-账号生命周期/03-登录弹窗.md)

### 3.5 实训账户简卡

| 区域 | 内容 |
|---|---|
| 标题行 | "实训账户" + 右侧箭头 |
| 数据行 | 4 个核心数据 |

**4 个核心数据**：

| 数据 | 说明 |
|---|---|
| 账户规模 | 用户实训账户的初始规模（如 "$5,000"）|
| 账户状态 | 状态标签（"活跃" / "锁定"）|
| 当前净值 | 当前账户净值（如 "$5,234.56"）|
| 持仓盈亏 | 当前未平仓持仓的盈亏（如 "+$120.00" / "-$80.50"）|

**视觉规则**：

- 盈亏色彩：盈利 `#F44336` 红色，亏损 `#2DC771` 绿色（金融行业涨红跌绿惯例）
- 状态标签：活跃 `#2DC771` 绿，锁定 `#FF9F1C` 橙

**点击行为**：跳转实训账户详情页（待输出）。

**特殊场景：用户没有实训账户**

整张卡片替换为"领取实训账户"引导卡片：

| 区域 | 内容 |
|---|---|
| 标题 | "领取你的实训账户" |
| 描述 | "完成新手任务即可获得 $1,000 实训账户，开启实训之旅" |
| CTA 按钮 | "立即领取"（主色按钮）|

点击"立即领取"跳转账户领取流程（外部 H5）。

**游客态**：

- 卡片显示"登录后查看你的实训账户"
- 点击触发[登录弹窗](../01-账号生命周期/03-登录弹窗.md)

### 3.6 快捷入口

3 个图标按钮横向均分排列：

| 入口 | 图标 | 文案 | 跳转 |
|---|---|---|---|
| 训练 | 训练图标 | 训练 | 切换底部 Tab 到训练 Tab |
| 学习 | 学习图标 | 学习 | 切换底部 Tab 到学习 Tab |
| 邀请 | 邀请图标 | 邀请 | 跳转邀请中心二级页面 |

**注**：训练 / 学习 与底部 Tab 重复，属于"多入口冗余"设计，为提升首页快捷触达。

**游客态**：图标可见，点击触发[登录弹窗](../01-账号生命周期/03-登录弹窗.md)。

### 3.7 火象专栏区域

| 元素 | 内容 |
|---|---|
| 模块标题 | "火象专栏" |
| 标题装饰 | 标题下方的小红线（主色 `#E72737`）|
| 内容区 | 瀑布流文章卡片（详见 [02-火象专栏](./02-火象专栏.md)）|

**首屏可见**：火象专栏的前 1-2 张卡片在首屏可见，用户向下滚动看到更多。

**滚动吸顶**：火象专栏标题在滚动到最上方时**吸顶**，方便用户在浏览长列表时仍可识别当前模块。

## 4. 关键交互

### 4.1 下拉刷新

用户在首页向下拖拽到顶部以上可触发下拉刷新：

- 刷新所有数据：banner、等级、评分、实训账户、火象专栏列表
- 刷新动画：顶部下拉指示器 + "正在刷新..." 文字
- 刷新成功：显示"刷新成功"Toast 1 秒后消失
- 刷新失败：显示"刷新失败，请检查网络"Toast

### 4.2 火象专栏交互

#### 4.2.1 点击文章卡片

- 跳转 [文章详情页](./03-文章详情页.md)
- 跳转时**浏览量 +1**（仅记录"打开详情页"，不区分用户停留时长，**不去重**）
- 浏览量显示规则：< 1 万显示具体数字（如"823"）；≥ 1 万显示 "X.X 万"

#### 4.2.2 列表快速点赞

用户可直接在列表卡片点击点赞图标进行快速点赞：

- 点赞状态切换：未点赞 → 已点赞（红色填充）/ 已点赞 → 取消（灰色边框）
- 数字实时更新（+1 / -1）
- **与文章详情页点赞状态同步**（用户在列表点赞过的文章，进入详情页应显示已点赞）
- **不增加浏览量**

#### 4.2.3 列表快速分享

用户可直接在列表卡片点击分享图标拉起分享流程：

- 拉起分享底部弹窗（与文章详情页分享一致）
- 分享渠道：保存图片 / 微信好友 / 朋友圈 / 复制链接 / 系统分享面板
- **不增加浏览量**

#### 4.2.4 游客态点赞 / 分享

游客态点击点赞 / 分享 → 触发[登录弹窗](../01-账号生命周期/03-登录弹窗.md)，登录成功后自动完成点赞 / 分享动作。

### 4.3 滚动行为

- 顶部导航栏**始终固定**（不随滚动消失）
- Banner、等级简卡、评分简卡、实训账户简卡、快捷入口**随页面滚动**
- 火象专栏标题**吸顶**（滚动到最上方时固定在导航栏下方）

### 4.4 切换 Tab 后回到首页

用户从其他 Tab 切回首页时：

- 默认保留上次的滚动位置
- 不自动刷新数据（除非用户主动下拉）
- 等级、评分、实训账户数据使用最近一次拉取的缓存

### 4.5 数据更新触发

用户在其他模块完成动作后，回到首页时数据应同步更新：

| 触发场景 | 受影响数据 |
|---|---|
| 用户完成任务 | 等级 XP / 等级标签 / 评分 |
| 用户领取实训账户 | 实训账户简卡（从"领取卡片"切换为"账户数据"）|
| 用户在外部 WebTrader 交易完成回流 | 实训账户当前净值、持仓盈亏 |
| 用户接收新消息 | 顶部消息角标 |

实现方式：返回首页时检测是否有数据更新事件，按需刷新。具体实现由前端架构决定。

## 5. 异常态

| 异常 | 表现 | 处理 |
|---|---|---|
| Banner 接口失败 | banner 不展示 | 整块隐藏，下方内容上移 |
| 等级数据接口失败 | 等级简卡数据为空 | 显示骨架屏 / "数据加载失败"占位 |
| 评分数据接口失败 | 评分简卡数据为空 | 显示骨架屏 / "数据加载失败"占位 |
| 实训账户数据失败 | 实训账户简卡数据为空 | 显示骨架屏 / "数据加载失败"占位 |
| 火象专栏接口失败 | 列表为空 | 显示"加载失败，下拉刷新重试" |
| 网络断开 | 全部数据无法加载 | 显示全局网络异常提示 |
| 部分数据加载慢 | 各模块独立加载 | 已加载的部分先显示，加载中的部分显示骨架屏 |

## 6. 接口约束

| 能力 | 说明 |
|---|---|
| 首页聚合接口 | 返回首页所需的全部数据（推荐）：等级、评分、实训账户、消息未读数等 |
| Banner 配置接口 | 返回当前生效的 banner 配置列表 |
| 评分数据接口 | 返回当前用户的当周评分与评级（详细计算规则见独立评分体系模块）|
| 火象专栏列表接口 | 详见 [02-火象专栏](./02-火象专栏.md) |
| 消息未读数接口 | 返回当前用户的未读消息数 |

接口的具体定义、字段、协议由后端开发设计，本文档仅描述业务诉求。

**性能要求**：

- 首屏关键数据（等级、评分、实训账户、banner、专栏前几条）应在 1 秒内呈现
- 推荐使用首页聚合接口，减少首屏请求数

游客态首页可正常浏览大部分内容：

| 元素 | 游客态行为 |

| 实训账户简卡 | 显示"登录后查看你的实训账户"+ 登录引导 |
