# 03-课程详情页（免费课）

| 字段 | 内容 |
|---|---|
| 模块名称 | 课程详情页（免费课） |
| 业务归属 | 学习 Tab |
| 入口路径 | 学习主页 / 免费课程分类列表 / 训练页任务关联跳转 |
| 页面层级 | 三级 |
| 关联文档 | [01-学习主页面](./01-学习主页面.md)、[02-免费课程分类列表](./02-免费课程分类列表.md)、[06-课程播放页](./06-课程播放页.md) |

---

## 1. 页面定位

免费课程详情页是用户在学习 Tab 内查看单门免费课程详细信息、进入播放的页面。

V1 已登录用户可观看所有免费课程，无任务解锁限制。

---

## 2. 入口与跳转

### 入口

| 入口 | 触发场景 |
|---|---|
| 免费课程分类列表 → 课程卡片 | 用户主动浏览选择 |
| 个人学习中心 → 已学课程 | 用户继续学习历史课程 |
| 训练页任务关联跳转（V1 课程已与任务解耦，但任务相关页面可能仍跳此页）| 间接路径 |

### 出口

| 出口 | 触发条件 |
|---|---|
| [06-课程播放页](./06-课程播放页.md) | 用户点击"立即学习" / "继续学习" |
| 返回上一页 | 顶部返回按钮 |

---

## 3. 页面结构

### 3.1 整体布局

| 顺序 | 区域 | 说明 |
|---|---|---|
| 1 | 顶部导航栏 | 返回 + 标题"课程详情" |
| 2 | 课程封面区 | 课程封面图（顶部大图）|
| 3 | 标题与简介区 | 课程标题、所属主题、简介 |
| 4 | 课程目录 | 章节列表 |
| 5 | 主按钮 | "立即学习" / "继续学习"（固定底部）|

### 3.2 课程封面区

| 元素 | 说明 |
|---|---|
| 封面图 | 全宽展示，按 16:9 比例 |
| 标题 | 课程标题（22px Semibold）|
| 标签 | 主题标签（如"基本面分析"）|

### 3.3 标题与简介区

| 元素 | 内容 |
|---|---|
| 课程标题 | 22px Semibold |
| 课程主题标签 | 6 大主题之一（交易基础 / 技术分析 / 基本面分析 / 风险管理 / 交易心理 / 品种解读） |
| 课程简介 | 富文本介绍，支持图文（最多展示 3-5 段）|
| 学习人数（可选）| V1 [待对齐] 是否展示 |

### 3.4 课程目录

显示课程的章节列表：

| 字段 | 说明 |
|---|---|
| 章节序号 | 1 / 2 / 3 ... |
| 章节标题 | 如 "第一节：什么是基本面分析" |
| 章节时长 | 如 "10:23" |
| 学习状态 | 已学习（绿色对勾）/ 未学习 / 进行中（继续观看）|

**点击章节**：直接跳转 [课程播放页](./06-课程播放页.md) 并定位到该章节。

### 3.5 主按钮

底部固定按钮：

| 状态 | 按钮 | 行为 |
|---|---|---|
| 用户从未学过 | "立即学习" | 跳转播放页第一章节 |
| 用户已学过部分 | "继续学习"（含进度提示如 "已学 30%"）| 跳转播放页上次观看位置 |
| 用户已学完 | "重新学习" | 跳转播放页第一章节 |

---

## 4. 关键交互

### 4.1 学习进度记忆

进入课程详情页时，从后端拉取用户在该课程的最远学习位置：

- 章节级别：哪一章已学完
- 章节内时间点：未学完的章节中，上次观看的时间点

### 4.2 章节顺序

V1 章节按运营在后台配置的顺序展示，**不强制按顺序学习**（用户可自由跳转任意章节）。

---

## 5. 异常态

| 异常 | 表现 | 处理 |
|---|---|---|
| 课程已下线 | 详情接口返回不存在 | 提示"课程已下线"，返回上一页 |
| 网络不可用 | 数据加载失败 | 显示"加载失败，点击重试" |
| 章节列表加载失败 | 章节为空 | 局部显示加载失败，主区域仍可见 |
| 封面图加载失败 | 图片位置 | 占位图灰色背景 |

---

## 6. 接口约束

| 能力 | 说明 |
|---|---|
| 拉取课程详情 | 根据课程 ID 返回完整内容（封面、标题、简介、章节列表）|
| 拉取学习进度 | 返回用户在该课程的最远学习章节 + 时间点 |

接口的具体定义、字段、协议由后端开发设计，本文档仅描述业务诉求。

---

## 7. 游客态

游客态可浏览课程详情：

| 行为 | 游客态 |
|---|---|
| 查看课程详情 | 可以 |
| 点击"立即学习" | 触发[登录弹窗](../01-账号生命周期/03-登录弹窗.md)，登录后跳转播放页 |

---

## 8. V1 范围限制

明确**不在 V1 范围**的功能：

| 功能 | 说明 |
|---|---|
| 课程评价 / 评分 | 不支持 |
| 相关课程推荐 | 不支持 |
| 课程笔记 | 不支持 |
| 章节试看（付费课才有概念，免费课全开）| 不适用 |
| 任务解锁限制 | V1 已移除（已登录用户全部可看）|
