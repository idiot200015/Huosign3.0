## 1. 页面定位

课程播放页是用户实际观看免费课程视频的页面。使用阿里云视频播放器接入。

V1 仅免费课在 App 内播放；付费课程在小鹅通通过 webview 观看（不在本页面承载）。

---

## 2. 入口与跳转

### 入口

| 入口 | 触发 |
|---|---|
| 课程详情页 → "立即学习" | 进入第一章节 |
| 课程详情页 → "继续学习" | 进入上次观看位置 |
| 课程详情页 → 章节列表点击 | 进入指定章节 |
| 个人学习中心 → 已学课程 → 继续学习 | 进入上次位置 |

### 出口

| 出口 | 触发 |
|---|---|

| 切换章节 | 章节列表点击其他章节 |

## 3. 页面结构

### 3.1 整体布局

| 区域 | 说明 |
|---|---|
| 视频播放区 | 顶部，按 16:9 比例展示视频 |
| 标题栏 | 视频区下方，章节名 + 课程名 |
| 章节列表 | 当前课程的所有章节，可切换 |
| 章节信息 | 章节描述、时长 |

### 3.2 视频播放区

| 元素 | 说明 |
|---|---|
| 播放器 | 阿里云视频播放器 SDK |
| 播放控件 | 播放 / 暂停 / 进度条 / 时间 |
| 全屏切换 | 支持横屏全屏 |
| 倍速 | 0.75x / 1.0x / 1.25x / 1.5x / 2.0x |
| 关闭 | 返回上一页 |

### 3.3 章节列表

视频下方展示当前课程的所有章节：

| 字段 | 说明 |
|---|---|
| 章节序号 | 1 / 2 / 3 ... |
| 章节标题 | 章节名 |
| 章节时长 | 如 "10:23" |
| 学习状态 | 已学习 ✓ / 进行中 / 未学习 |
| 当前章节高亮 | 当前正在播放的章节用主色标识 |

点击其他章节可切换播放。

### 3.4 章节信息

视频下方展示当前章节的详细信息：

- 章节描述（运营在后台配置的富文本）
- 章节时长

## 4. 视频播放（阿里云）

### 4.1 播放器能力

| 能力 | 说明 |
|---|---|
| 自适应码率 | 阿里云 SDK 根据网络自动选择码率 |
| 倍速播放 | 0.75x / 1.0x / 1.25x / 1.5x / 2.0x |
| 全屏切换 | 支持横屏全屏 / 退出全屏 |
| 进度调整 | 拖动进度条 / 跳转 |
| 静音切换 | 支持 |
| 视频画质切换 | 用户可手动选择画质（如 720p / 1080p）|

### 4.2 学习进度记忆

V1 支持学习进度记忆：

| 维度 | 说明 |
|---|---|
| 记忆粒度 | 章节级 + 章节内时间点 |
| 上传时机 | 用户暂停 / 切换章节 / 退出页面时上传当前进度 |
| 上传频次 | 每分钟上传一次心跳（避免频繁请求）|
| 进度恢复 | 用户下次进入课程时，自动从上次位置继续 |

**章节标记"已学习"的规则**：

| 触发条件 | 状态 |
|---|---|
| 用户观看至章节末尾（≥ 95%） | 自动标记"已学习" |
| 用户观看 < 95% 且暂停 | 标记"进行中"，记录进度 |
| 用户从未观看 | 状态"未学习" |

### 4.3 章节切换

用户在播放页切换章节：

- 当前章节进度自动保存
- 新章节从用户上次观看位置开始
- 章节列表实时高亮当前播放章节

## 5. 关键交互

### 5.1 横屏全屏播放

用户点击全屏按钮：

- 视频区扩展至全屏（横屏方向）
- 状态栏隐藏
- 播放控件浮层显示，3 秒无操作自动隐藏
- 用户点击"退出全屏"或系统返回手势退出

### 5.2 后台播放

V1 不支持后台播放（用户离开 App 时视频暂停）。

### 5.3 弱网处理

弱网时阿里云 SDK 自动降低码率。如果完全断网：

- 显示"网络异常，请检查网络"提示
- 用户恢复网络后可继续播放（从断点开始）

---

## 6. 异常态

| 异常 | 表现 | 处理 |
|---|---|---|
| 视频加载失败 | 视频区域 | 显示"视频加载失败，点击重试" |
| 视频正在转码 | 视频区域 | 显示"视频处理中，请稍后再试" |
| 章节切换失败 | 切换无效 | Toast"切换失败，请重试" |
| 进度上传失败 | 后台静默失败 | 不影响用户播放，下次心跳重试 |
| 用户中途切到其他 App | 视频自动暂停 | 用户回来后从暂停位置继续 |

---

## 7. 接口约束

| 能力 | 说明 |
|---|---|
| 获取视频播放凭证 | App 调用阿里云 SDK 时需要的播放凭证（VID + 凭证）|
| 上传学习进度 | 心跳接口，定期上传当前播放进度 |
| 标记章节已学习 | 用户观看至 ≥ 95% 时自动调用 |

接口的具体定义、字段、协议由后端开发设计，本文档仅描述业务诉求。

---

## 8. 游客态

V1 课程播放页**不允许游客访问**：

- 课程详情页用户点击"立即学习"时已触发[登录弹窗](../01-账号生命周期/03-登录弹窗.md)
- 仅已登录用户可进入播放页

## 9. 性能要求

| 项 | 要求 |
|---|---|
| 视频首次播放 | < 3 秒（P95，4G 网络）|
| 章节切换响应 | < 1 秒 |
| 进度上传成功率 | > 99% |
