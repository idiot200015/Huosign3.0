## 1. 页面定位

学习 Tab 是火象 3.0 的**核心商业页面**，承载平台主要收入来源（付费课程购买）和教育内容消费（免费课程学习）。

定位区别：
- **首页**：流量与内容消费入口
- **训练页**：业务执行核心
- **学习页**：商业与教育内容核心
- **我的页**：个人中心与设置

---

## 3. 页面结构

### 3.1 整体布局

页面采用**纵向滚动**布局，从上到下：

| 顺序 | 区域 | 高度（参考）| 说明 |
|---|---|---|---|
| 1 | 顶部导航栏 | 44px | 标题"学习" + 右侧"个人学习中心"入口 |
| 2 | 免费课程主题分类（首屏视觉）| 不定 | 6 大主题入口 |
| 3 | 直播模块 | 约 130px | 跳转小鹅通 |
| 4 | 付费课程区 | 不定 | 直升 / 进阶 / 重训 三 Tab |

### 3.2 顶部导航栏

| 元素 | 内容 |
|---|---|
| 左侧 | 无 |
| 标题 | "学习" |
| 右侧 | "个人学习中心"入口图标 + 角标（未读优惠券 / 新订单等）|

**右上角入口规则**：

- 图标点击跳转 [08-个人学习中心](./08-个人学习中心.md)
- 角标显示规则：用户拥有 ≥ 1 张未使用优惠券时显示红点（具体规则 [待对齐]）

### 3.3 免费课程主题分类（首屏视觉）

学习页首屏主视觉为**免费课程的 6 大主题分类入口**，便于游客和未购用户快速浏览。

**6 大主题**（运营在后台配置具体课程归属）：

| 主题 | 覆盖内容 |
|---|---|
| 交易基础 | 品种 / 点差 / 杠杆 / 开平仓 / 订单类型 / 止盈止损 |
| 技术分析 | K 线 / 均线 / 趋势 / 形态 / 技术指标 / 支撑阻力 |
| 基本面分析 | 宏观经济 / 财经数据 / 央行政策 / 行业研究 / 事件驱动 |
| 风险管理 | 仓位管理 / 资金管理 / 风险回报比 / 止损策略 / 回撤控制 |
| 交易心理 | 情绪管理 / 交易纪律 / 复盘方法 / 交易系统建立 |
| 品种解读 | 各交易品种的特性、机制、历史行情、风险特征 |

> 注：6 大主题数量调整需要重新设计 + 发版（不是简单后台配置）。运营后台仅配置每门课程归属哪个主题。

**视觉规则**：

| 项 | 规则 |
|---|---|
| 排版 | 2 列 × 3 行网格布局，6 个主题入口 |
| 单个入口 | 主题图标 + 主题名称 |
| 卡片背景 | `#FFFFFF`，圆角 12px |
| 间距 | 卡片之间 12px |

**点击行为**：跳转 [02-免费课程分类列表](./02-免费课程分类列表.md)，展示该主题下的全部免费课程。

### 3.4 直播模块

详见 [09-直播模块](./09-直播模块.md)。

学习页内直播模块作为一个区块展示，包含：

| 元素 | 内容 |
|---|---|
| 状态标签 | 即将开播 / 正在直播 / 暂无直播 |
| 直播封面 | 运营配置的封面图 |
| 直播主题 | 直播标题 |
| 时间段 | 开始时间 - 结束时间 |
| 跳转入口 | "前往观看" / "查看详情" |

**无直播时**：直播模块隐藏（不占空间）。

### 3.5 付费课程区

| 区域 | 内容 |
|---|---|
| 模块标题 | "课程包" + 标题装饰（小红线主色 `#E72737`） |
| 顶部 Tab | 直升课 / 进阶课 / 重训课 |
| 内容区 | 当前 Tab 下的课程列表 |
| 查看更多 | 跳转 [04-付费课程列表](./04-付费课程列表.md) 完整列表 |

**Tab 默认定位**：进阶课（标准付费路径）。

**Tab 切换规则**：

| Tab | 默认展示规则 |
|---|---|
| 直升课 | 始终展示 |
| 进阶课 | 始终展示，默认 Tab |
| 重训课 | 始终展示。用户账户未锁定时点击 Tab，提示"暂时无需重训" |

**课程卡片字段**：

| 字段 | 说明 |
|---|---|
| 课程封面 | 运营配置的封面图 |
| 课程名称 | 如"初级训练课程" |
| 配套权益 | 如"升级到 $2,000 实训账户" |
| 价格 | 如"¥99"（DINPro Bold）|
| 状态标签 | 已拥有（已购）/ 立即购买 |
| 主按钮 | "立即购买" / "已拥有" |

**已购课程的展示**：

- 用户已购买的进阶课：卡片置灰显示"已拥有"，按钮变为"查看详情"
- 直升课和重训课：可重复购买（账户权益是一次性的，多次升级需多次购买）

## 4. 关键交互

### 4.1 下拉刷新

用户在学习页向下拖拽到顶部以上可触发下拉刷新：
- 刷新所有数据：免费课程主题、直播状态、付费课程列表、个人学习中心角标
- 刷新动画 + Toast 提示

### 4.2 切换付费课程 Tab

| 操作 | 行为 |
|---|---|
| 点击 Tab | 切换内容区 |
| 切换动画 | 滑动过渡 |
| Tab 状态保持 | 切换其他 Tab 后再切回学习页，保持上次 Tab 状态 |

### 4.3 已购课程的状态判定

App 启动时拉取用户已购订单数据，与课程列表合并展示：

- 已购的进阶课对应规模 → 卡片置灰显示"已拥有"
- 直升课 / 重训课 → 不论是否已购都允许再次购买

### 4.4 数据更新触发

| 触发场景 | 受影响数据 |
|---|---|
| 用户购买课程后回到学习页 | 对应课程卡片状态更新 |
| 用户使用优惠券后 | 个人学习中心角标更新 |
| 直播状态变化（开播 / 结束）| 直播模块状态实时更新 |

## 5. 异常态

| 异常 | 表现 | 处理 |
|---|---|---|
| 数据加载失败 | 各模块独立加载失败 | 局部错误提示 + 重试 |
| 直播接口失败 | 直播模块隐藏 | 不影响其他模块展示 |
| 已购数据加载失败 | 课程状态不准确 | 默认展示"立即购买"，购买时后端二次校验防止重复购买 |
| 网络断开 | 全部加载失败 | 显示全局网络异常提示 |

## 6. 接口约束

| 能力 | 说明 |
|---|---|
| 学习页聚合接口 | 返回主题列表、直播状态、付费课程列表、用户已购数据 |
| 6 大主题配置接口 | 返回当前生效的主题列表（V1 写死 6 个主题，但运营可后台配置课程归属）|
| 付费课程列表接口 | 按 Tab 类型返回课程列表 |
| 用户已购课程接口 | 返回用户已购的进阶课规模列表 |

接口的具体定义、字段、协议由后端开发设计，本文档仅描述业务诉求。

## 7. 游客态行为

游客态学习页可正常浏览大部分内容：

| 元素 | 游客态行为 |
|---|---|
| 顶部"个人学习中心"入口 | 点击触发[登录弹窗](../01-账号生命周期/03-登录弹窗.md) |
| 免费课程主题入口 | 可正常进入分类列表，可浏览课程详情，但点击播放触发登录 |
| 直播模块 | 可见，点击触发登录 |
| 付费课程区 | 可见课程列表，点击立即购买触发登录 |

## 8. V1 范围限制

明确**不在 V1 范围**的功能：

| 功能 | 说明 |
|---|---|
| 课程搜索 | 学习页顶部不放搜索框 |
| 任务解锁机制 | V1 已登录用户全部免费课可看，无任务解锁限制 |
| 课程评分 / 评价 | 不支持 |
| 相关推荐 | 不支持 |
| 课程收藏 | 不支持 |
