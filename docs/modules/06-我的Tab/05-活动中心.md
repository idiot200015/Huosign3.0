## 1. 模块定位

活动中心是用户查看平台运营活动的统一聚合页。承载所有运营在后台发布的活动卡片入口。

V1 活动中心**仅作活动入口聚合**，不承载活动详情逻辑（详情由活动详情页 / H5 实现）。

---

## 2. 入口与跳转

### 入口

- 我的主页 → 业务入口网格 → 活动中心

### 出口

| 出口 | 触发条件 |
|---|---|
| 活动详情页 / H5 | 用户点击活动卡片 |
| 返回我的页 | 顶部返回按钮 |

---

## 3. 页面结构

### 3.1 整体布局

| 区域 | 内容 |
|---|---|
| 顶部导航栏 | 返回 + 标题"活动中心" |
| Tab 切换 | 进行中 / 即将开始 / 已结束 |
| 活动列表 | 当前 Tab 下的活动卡片 |

### 3.2 顶部 Tab

| Tab | 内容 |
|---|---|
| 进行中 | 当前正在进行的活动（默认 Tab）|
| 即将开始 | 未来即将开始的活动 |
| 已结束 | 已结束的活动 |

### 3.3 活动卡片字段

每张活动卡片展示：

| 字段 | 说明 |
|---|---|
| 活动封面 | 全宽展示，按 16:9 比例 |
| 活动标题 | 14px Medium |
| 活动简介 | 一行摘要，14px Regular |
| 时间段 | 如 "10-20 ~ 10-31" |
| 状态标签 | 进行中 / 即将开始 / 已结束 / 倒计时（即将开始时显示倒计时）|
| 主按钮 | "立即参与" / "查看详情" / "已结束" |

视觉规则：

- 卡片整体圆角 12px
- 状态标签按状态使用不同颜色（进行中：主色 / 即将开始：橙 / 已结束：灰）

### 3.4 加载策略

| 项 | 规则 |
|---|---|
| 排序 | 进行中 / 即将开始：按时间正序；已结束：按时间倒序 |
| 默认加载 | 20 条 |
| 上拉加载 | 每次 20 条 |
| 下拉刷新 | 重新拉取 |

---

## 4. 关键交互

### 4.1 点击活动卡片

按活动配置的跳转类型：

| 跳转类型 | 行为 |
|---|---|
| 内部活动详情页 | 跳转 App 内活动详情页 |
| 外部 H5 | 在 webview 内打开 H5 |
| 跳转其他页面 | 如跳转某个特定 Tab / 模块 |

详细跳转配置由运营在后台设置，详见 [10-活动管理（待输出）]。

### 4.2 倒计时展示

状态为"即将开始"且距离开始时间 ≤ 24 小时的活动，卡片上显示倒计时：

- 格式：HH:MM:SS
- 每秒更新
- 倒计时结束时活动状态自动切换为"进行中"

### 4.3 已结束活动

| 项 | 规则 |
|---|---|
| 卡片视觉 | 整体灰化（包括封面图）|
| 主按钮 | "查看详情"（仍可点击查看活动归档信息）|

---

## 5. 空状态

| 场景 | 展示 |
|---|---|
| 进行中 Tab 无活动 | "暂无进行中的活动" |
| 即将开始 Tab 无活动 | "暂无即将开始的活动" |
| 已结束 Tab 无活动 | "暂无已结束的活动" |

居中插画 + 文案，无 CTA。

---

## 6. 异常态

| 异常 | 表现 | 处理 |
|---|---|---|
| 列表加载失败 | 列表为空 | 显示"加载失败，下拉刷新重试" |
| 上拉加载失败 | 底部提示 | "加载失败，点击重试" |
| 活动跳转失败 | 跳转无效 | Toast"页面加载失败" |
| 活动已下线（用户列表中点击）| 详情接口返回不存在 | 提示"活动已结束或已下线"，返回列表 |
| 活动封面加载失败 | 占位图 | 灰色背景兜底 |

---

## 7. 接口约束

| 能力 | 说明 |
|---|---|
| 拉取活动列表 | 按 Tab 类型分页拉取 |
| 活动数据 | 返回卡片所需字段：封面、标题、简介、时间段、状态、跳转类型、跳转目标 |

接口的具体定义、字段、协议由后端开发设计，本文档仅描述业务诉求。

---

## 8. 后台配置

活动由运营在后台管理：

- 创建活动（标题、简介、封面、时间段、跳转类型、跳转目标）
- 活动上下架
- 活动排序 / 置顶
- 活动归档

详见 [98-10-活动管理（待输出）]。

---

## 9. V1 范围限制

| 功能 | 说明 |
|---|---|
| 活动详情页（App 内）| V1 简化，主要通过 H5 承载活动详情 |
| 活动报名 | V1 不在活动中心内承载报名，由跳转目标决定 |
| 活动分享 | V1 不在活动中心内做分享 |
| 活动通知 | V1 不主动推送活动通知 |
| 活动评论 | 不支持 |
| 活动排行 | 不支持 |
| 活动收藏 | 不支持 |
