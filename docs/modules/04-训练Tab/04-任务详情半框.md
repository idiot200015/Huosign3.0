## 1. 模块定位

任务详情半框是 App 内统一的任务详情展示组件，以底部弹窗形式呈现。所有"查看任务详情"场景均通过此半框实现，避免任务详情独立成页带来的层级跳转。

适用场景：
- 查看任务规则、奖励、当前进度
- 开始任务（接任务）
- 任务失败后的重新挑战
- 查看历史任务详情（含已失效任务）
- 查看现金挑战详情

## 4. 半框结构

### 4.1 通用结构

| 区域 | 内容 |
|---|---|
| 顶部 | × 关闭按钮 + 拖拽指示条（小横线） |
| 任务标题区 | 任务编号 + 任务名 + 状态标签 |
| 任务信息区 | 任务类型 / 使用账户 / 奖励等基础信息 |
| 任务内容区 | 任务规则的详细描述（含交易要求、判定标准等） |
| 进度区（如适用）| 当前进度数据 |
| 操作区 | 根据状态变化的按钮组 |

### 4.2 任务标题区

| 字段 | 说明 |
|---|---|
| 任务编号 | "Lv X-模 0Y" / "Lv X-实 0Y" / "现金挑战 0Z" |
| 任务名 | 任务名称（如 "Lv2-模 01"对应名称） |
| 状态标签 | 见状态标签清单 |

**状态标签清单**：

| 状态 | 标签文字 | 颜色 |
|---|---|---|
| 未开启（当前等级可做）| 未开启 | 灰色 |
| 进行中 | 进行中 | 绿色 `#2DC771` |
| 已完成 | 挑战成功 | 绿色 `#2DC771` |
| 已失败 | 挑战失败 | 红色 `#F44336` |
| 已失效 | 已失效 | 灰色 `#999999` |
| 未解锁（现金挑战）| 未解锁 | 橙色 `#FF9F1C` |

### 4.3 任务信息区

| 字段 | 说明 |
|---|---|
| 任务类型 | 日常任务 / 实训任务 / 现金挑战 |
| 使用账户 | 模拟账户 / 实训账户 |
| 奖励类型 | XP / 现金奖励 |
| 奖励数额 | 具体数值（如 "+10 XP" / "+$50"）|
| 邀请门槛（仅现金挑战）| 该挑战需要的邀请条件 |

### 4.4 任务内容区

任务的详细规则描述，由后端配置返回的富文本：

- 交易要求（如"完成 1 笔交易"）
- 持仓时长要求（如"持仓时间 ≥ 3 分钟"）
- 盈亏判定（如"已实现盈亏 ≥ X"）
- 其他特殊规则

### 4.5 进度区（仅进行中状态）

展示用户当前任务进度：

| 字段 | 说明 |
|---|---|
| 进度文字描述 | 如"已完成 2/3 笔交易"|
| 进度条（可选）| 任务可量化时显示进度条 |
| 当前盈亏 | 任务期间的累计盈亏 |

## 5. 操作区（按状态分支）

不同任务状态显示不同的按钮组：

### 5.1 未开启（当前等级可做）

```
[ 取消 ]  [ 开始任务 ]
```

- "取消"：关闭半框
- "开始任务"：
  - 校验用户是否有其他进行中任务（互斥校验）
  - 如有，弹出冲突提示弹窗
  - 如无，开启任务，状态变为"进行中"
  - 半框关闭，训练页"当前任务横条"出现该任务

**首次接任务的归属告知**：

如用户首次接此类任务（升级 / 现金）且有"待追溯"邀请，先弹出归属告知弹窗（详见 [02-邀请中心](../02-跨Tab通用/02-邀请中心.md) 第 3.4 节），用户确认后才正式开始任务。

### 5.2 进行中

```
[ 退出挑战 ]  [ 去训练 ]
```

- "退出挑战"：
  - 二次确认弹窗"确定退出？退出后任务标记为挑战失败，进度清零。"
  - 确认后任务状态变为"挑战失败"，进入挽留态
- "去训练"：
  - 跳转 [10-WebTrader 中转](./10-WebTrader中转.md)
  - 半框关闭

### 5.3 挑战失败（挽留态）

```
[ 重新挑战 ]  [ 关闭 ]
```

- "重新挑战"：任务状态重置为"进行中"，进度清零
- "关闭"：关闭半框（用户可在训练页选其他任务）

### 5.4 挑战成功

```
[ 关闭 ]
```

无任何操作按钮（任务终态，不可重做）。

显示获得的奖励数据。

### 5.5 已失效

```
[ 关闭 ]
```

无任何操作按钮（任务因升级而失效，不可补做）。

显示状态文字："此任务已因等级升级而失效，不可再做。"

### 5.6 未解锁（现金挑战）

```
[ 完成邀请解锁 ]
```

- 点击"完成邀请解锁" → 拉起邀请海报弹窗（现金挑战场景）
- 不可点击"开始任务"

显示当前邀请进度："已邀请 X / 需邀请 Y"。

## 6. 关键交互

### 6.1 多入口的状态一致性

无论从哪个入口进入半框，相同任务的展示信息一致（任务编号、名称、奖励、规则）；不同入口主要影响**操作区按钮**和**进度区数据**。

### 6.2 互斥任务冲突弹窗

用户点击"开始任务"且已有进行中任务时：

```
弹窗：
  标题：当前已有进行中任务
  正文：你正在进行 [任务名]，需要先完成或退出后才能开启新任务。
  按钮：取消 / 去查看当前任务
```

- "取消"：关闭弹窗，留在半框
- "去查看当前任务"：关闭半框 + 弹窗，重新打开当前进行中任务的半框

### 6.3 退出挑战的二次确认

用户在进行中状态点击"退出挑战"：

```
弹窗：
  标题：确定退出当前任务？
  正文：退出后任务将标记为挑战失败，已完成进度清零。可重新挑战。
  按钮：取消 / 确认退出
```

### 6.4 半框高度的内容自适应

不同状态半框高度可微调（如"未解锁"状态因有邀请进度区可能更高）。

## 7. 异常态

| 异常 | 表现 | 处理 |
|---|---|---|
| 任务详情接口失败 | 半框内容为空 | 显示"加载失败，点击重试" |
| 开始任务接口失败 | 用户点击后无响应 | Toast"操作失败，请重试" |
| 互斥校验时检测到状态变化 | 用户已开始另一个任务 | 提示"账户状态已变化"，刷新数据 |
| 任务规则配置缺失 | 任务内容区为空 | 显示"任务规则加载失败" |
| 网络断开 | 半框无法操作 | 半框显示网络异常 |

## 8. 接口约束

| 能力 | 说明 |
|---|---|
| 任务详情接口 | 根据任务 ID 返回任务详情（基础信息、规则、奖励、用户当前进度、当前状态）|
| 开始任务 | 接收用户开始任务请求，校验互斥后开启任务 |
| 退出任务 | 用户主动退出任务，标记为挑战失败 |
| 重新挑战 | 失败任务的进度归零，状态重置为进行中 |
| 任务进度更新 | 由后端基于交易事件自动更新（不在前端触发）|

接口的具体定义、字段、协议由后端开发设计，本文档仅描述业务诉求。
