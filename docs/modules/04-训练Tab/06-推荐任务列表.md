## 1. 页面定位

推荐任务列表页是用户在训练主页"任务区"看到 3 个推荐任务后，点击"查看更多"进入的完整任务列表页。

页面展示用户**当前等级下、未做过且未失效**的所有任务，便于用户全面浏览并选择接哪个任务。

页面有 2 个独立入口对应 2 类任务：

| 入口来源 | 列表内容 |
|---|---|
| 实训账户卡片 → 查看更多 | 当前等级所有"实训任务"+ "现金挑战" |
| 模拟账户卡片 → 查看更多 | 当前等级所有"日常任务" |

注：现金挑战的入口在实训账户卡片下，但 V1 推荐任务列表是否包含现金挑战 [待对齐] —— 文档先按"包含"撰写。

## 3. 页面结构

### 3.1 顶部导航栏

| 元素 | 内容 |
|---|---|
| 左侧 | 返回按钮 |
| 标题 | "实训账户任务" / "模拟账户任务"（按入口动态切换）|
| 右侧 | 无 |

### 3.2 任务列表

页面主体为任务卡片列表，按任务编号顺序展示。

**列表特性**：

| 项 | 规则 |
|---|---|
| 排序 | 默认按任务编号正序（如 Lv2-模 01、Lv2-模 02 ...）|
| 加载策略 | 默认加载 20 条，上拉加载更多 |
| 下拉刷新 | 重新拉取列表 |
| Tab / 筛选 | V1 不做 Tab 切换、不做筛选 |

### 3.3 任务卡片字段

每张任务卡片展示：

| 字段 | 说明 |
|---|---|
| 任务编号 | 如 "Lv2-模 01" |
| 任务名称 | 如 "完成 1 笔交易并持仓 ≥ 3 分钟" |
| 任务类型标签 | "Lv2-模拟" / "Lv2-实训" / "现金挑战" |
| 任务简介 | 单行摘要，最多 1 行 |
| XP 奖励 | 完成可获得的 XP（如 "+10 XP"）|
| 现金奖励（仅现金挑战）| 完成可获得的现金（如 "¥100"）|
| 任务状态 | "可做" / "进行中" / "已完成" / "已失效"  / "未解锁"|
| 主按钮 / 状态标签 | 按状态展示不同 |

### 3.4 任务状态展示规则

| 任务状态 | 卡片视觉 | 操作按钮 |
|---|---|---|
| 可做（默认）| 正常视觉 | "去挑战" |
| 进行中 | 任务卡片右上角"进行中"标签 | "查看进度" |
| 已完成 | 视觉灰化 + "已完成"标签（绿色 `#2DC771`）| 无按钮（卡片不可点击）|
| 已失效 | 视觉灰化 + "已失效"标签（橙色 `#FF9F1C`）| 无按钮（卡片不可点击）|
| 未解锁（仅现金挑战）| 灰色锁图标 + "邀请 X 人解锁" | "去邀请解锁" |

## 4. 关键交互

### 4.1 点击任务卡片

| 状态 | 行为 |
|---|---|
| 可做 / 进行中 | 弹出 [04-任务详情半框](./04-任务详情半框.md)，展示任务详情 |
| 已完成 / 已失效 | 不可点击，无任何反馈 |
| 未解锁（现金挑战）| 弹出现金挑战详情半框，展示邀请进度 |

### 4.2 互斥任务的提示

由于任务三类全互斥，用户已有进行中任务时，在推荐任务列表点击其他任务：

- 任务详情半框正常打开
- 半框内"开始挑战"按钮置灰
- 提示文案"你正在进行 [任务名]，请先完成或退出后再开始新任务"

详见 [04-任务详情半框](./04-任务详情半框.md)。

### 4.3 列表刷新

| 触发场景 | 行为 |
|---|---|
| 用户接受任务后返回 | 列表刷新，对应任务状态变为"进行中" |
| 用户完成任务后返回 | 列表刷新，对应任务变为"已完成" |
| 用户升级后访问 | 列表自动加载新等级的任务（之前等级的任务不展示）|

## 5. 空状态

### 5.1 当前等级所有任务都已做完

| 区域 | 内容 |
|---|---|
| 居中插画 | [待 UI 提供] |
| 文案 | "你已完成本等级的全部任务，邀请好友升级后解锁新任务" |
| CTA | "去邀请好友"（跳转邀请中心 / 拉起海报）|

### 5.2 当前等级无任务（数据异常）

| 区域 | 内容 |
|---|---|
| 文案 | "暂无可做任务" |
| 操作 | 无 |

---

## 6. 异常态

| 异常 | 表现 | 处理 |
|---|---|---|
| 列表加载失败 | 列表为空 | 显示"加载失败，下拉刷新重试" |
| 上拉加载失败 | 底部 | 显示"加载失败，点击重试" |
| 任务点击后详情加载失败 | 半框无法弹出 | Toast"加载失败，请重试" |

---

## 7. 接口约束

| 能力 | 说明 |
|---|---|
| 拉取推荐任务列表 | 按"账户类型 + 当前等级"拉取列表，按任务编号排序 |
| 任务状态查询 | 列表中的每个任务返回当前状态（可做 / 进行中 / 已完成 / 已失效 / 未解锁）|

接口的具体定义、字段、协议由后端开发设计，本文档仅描述业务诉求。
