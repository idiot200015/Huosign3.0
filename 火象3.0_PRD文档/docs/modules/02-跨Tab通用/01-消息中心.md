## 1. 模块定位

消息中心承载火象 3.0 内**由运营在后台手动发布**的所有站内信，包括运营公告、活动通知、平台通告等。

V1 仅展示运营手动发布的消息，**不包含系统自动触发的消息**（如任务完成、升级、补贴金到账、邀请进展、安全提醒等）。这些场景的告知通过 App 内 Toast、推送、页面内角标等其他方式实现。

---

## 2. 入口与跳转

### 入口

- 首页顶部消息图标

### 出口

| 出口 | 触发条件 |
|---|---|
| 消息详情页 | 用户点击列表中任意一条消息 |
| 返回首页 | 用户点击顶部返回按钮 |

## 3. 消息中心列表页

### 3.1 页面结构

| 区域 | 内容 |
|---|---|
| 顶部导航 | 返回按钮 + 标题"消息" + 右上角"全部已读"按钮 |
| 消息列表 | 时间倒序排列，每条消息一个卡片 |
| 空状态 | 无消息时展示空状态 |

### 3.2 消息卡片字段

每条消息卡片仅包含 4 个字段：

| 字段 | 说明 |
|---|---|
| 标题 | 消息标题，最多 1 行，超出省略号 |
| 摘要 | 消息内容摘要，固定 1 行，超出省略号 |
| 时间 | 消息发送时间（具体格式见 3.3 节）|
| 已读 / 未读状态 | 未读消息左上角小红点 |

### 3.3 时间显示规则

| 时间区间 | 展示方式 |
|---|---|
| 1 分钟内 | 刚刚 |
| 1 分钟 ~ 1 小时 | X 分钟前 |
| 1 小时 ~ 24 小时 | X 小时前 |
| 昨天 | 昨天 HH:MM |
| 7 天内（非昨天）| 周一 / 周二 / ... HH:MM |
| 7 天前~ 当年 | MM-DD HH:MM |
| 跨年 | YYYY-MM-DD |

### 3.4 排序规则

- **统一按发送时间倒序**
- 已读 / 未读不影响排序
- 同一时刻的消息按消息 ID 倒序

### 3.5 加载规则

| 项 | 规则 |
|---|---|
| 默认加载 | 首屏 20 条 |
| 上拉加载 | 每次加载 20 条 |
| 下拉刷新 | 重新拉取最新消息 |
| 加载完毕 | 列表底部显示"已经到底啦" |

### 3.6 已读 / 未读状态

| 状态 | 视觉 |
|---|---|
| 未读 | 卡片左上角小红点 + 标题字色加深 |
| 已读 | 无小红点 + 标题正常字色 |

**已读触发**：用户点击消息进入详情页 → 该条消息标记为已读。

**全部已读**：右上角"全部已读"按钮 → 弹出确认 → 确认后所有未读消息标记为已读。

### 3.7 空状态

无消息时展示：
- 居中插画 / Icon **[待 UI 提供]**
- 文案"暂无消息"
- 不提供操作按钮

## 4. 消息详情页

### 4.1 页面结构

| 区域 | 内容 |
|---|---|
| 顶部导航 | 返回按钮 + 标题"消息详情" |
| 消息标题区 | 消息标题（大字号）+ 发送时间 |
| 消息正文 | 富文本内容（支持文字、图片、链接、加粗等基础富文本）|

### 4.2 富文本支持

后端发布的消息支持以下富文本元素：

| 元素 | 说明 |
|---|---|
| 文字 | 普通文字 |
| 加粗 | 强调内容 |
| 图片 | 内联图片，自适应宽度 |
| 链接 | 文字链接，点击跳转 H5 |
| 列表 | 有序 / 无序列表 |
| 分割线 | 段落分隔 |

详细富文本格式由运营后台配置 **[详见 98-运营配置体系/13-站内信公告（待输出）]**。

### 4.3 详情页交互

- **不支持跳转其他业务页面**（如不支持跳到训练页、活动页等）
- 详情页内的链接（运营在富文本中插入的）跳转 H5
- 详情页支持长按选择文字复制
- 详情页支持下拉返回手势

## 5. 未读数显示

### 5.1 显示位置

| 位置 | 显示规则 |
|---|---|
| 首页顶部消息图标 | 未读总数角标。1-99 显示具体数字；99+ 显示"99+" |
| App 图标角标 | 未读总数角标（iOS / Android 系统角标） |

### 5.2 角标更新时机

| 时机 | 行为 |
|---|---|
| App 启动时 | 拉取最新未读数 |
| 用户进入消息中心 | 进入即刷新未读数 |
| 用户点击消息阅读后 | 实时减少未读数 |
| 用户点击"全部已读"后 | 未读数清零 |
| 推送送达时 | 未读数实时增加（推送系统协同处理）|

### 5.3 角标清零

- 用户点击具体消息阅读后，单条消息计入已读，角标 -1
- 用户点击"全部已读"后，所有未读消息计入已读，角标清零

---

## 6. 消息保留时长

| 项 | 规则 |
|---|---|
| 服务端保留 | 永久保留 |
| 客户端缓存 | 当次会话缓存，重新打开 App 重新拉取 |

用户不支持手动删除消息（V1 不提供单条删除 / 清空全部功能）。

---

## 7. 关键交互

### 7.1 消息送达

- 运营在后台发布消息后，后端推送给所有目标用户
- 目标用户范围由运营在后台配置（如全体用户 / 指定用户群体）**[详见 98-13]**
- 用户当前在线 → 实时收到（消息中心列表自动刷新）
- 用户离线 → 下次启动 App 时拉取新消息

### 7.2 全部已读确认

用户点击右上角"全部已读"按钮：

```
弹窗：
  标题：标记全部为已读？
  正文：（无）
  按钮：取消 / 确认
```

确认后：
- 所有未读消息标记为已读
- 列表上的未读小红点全部消失
- 顶部消息图标的红点角标清零

### 7.3 网络异常时的列表行为

- 列表加载失败 → 显示"加载失败，点击重试"
- 上拉加载失败 → 底部显示"加载失败，点击重试"
- 下拉刷新失败 → Toast 提示"网络异常，请稍后重试"

---

## 8. 异常态

| 异常 | 表现 | 处理 |
|---|---|---|
| 网络不可用 | 列表加载失败 | 显示"加载失败，点击重试" |
| 后端接口超时 | 列表无响应 | 显示空状态 + 重试入口 |
| 富文本图片加载失败 | 图片位置显示占位图 | 占位图 + "图片加载失败" |
| 详情页消息已被运营删除 | 详情页接口返回不存在 | 提示"消息已不存在或已被删除"，返回列表 |
| 全部已读接口失败 | 操作未生效 | Toast"操作失败，请重试" |

---

## 9. 接口约束

| 能力 | 说明 |
|---|---|
| 拉取消息列表 | 分页拉取消息列表，支持时间倒序 |
| 拉取未读数 | 单独接口，用于角标显示 |
| 拉取消息详情 | 根据消息 ID 拉取详细内容（含富文本）|
| 标记单条已读 | 用户进入详情页时调用 |
| 标记全部已读 | 全部已读按钮调用 |

接口的具体定义、字段、协议由后端开发设计，本文档仅描述业务诉求。

---

## 10. V1 范围限制

明确**不在 V1 范围**的功能：

| 功能 | 说明 |
|---|---|
| 系统自动消息 | 任务完成、升级、补贴金到账、邀请进展、安全等系统消息不进消息中心 |
| 用户互发消息 | 不支持用户间发消息 |
| 客服 IM | 不支持客服回复消息 |
| 消息删除 / 清空 | 不支持用户删除消息 |
| 消息分类 / 筛选 | 不支持按类型筛选消息 |
| 推送系统 | 推送规则 [待 99-04 推送规范] |
