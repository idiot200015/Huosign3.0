## 1. 设计基础

### 1.1 设计稿尺寸

| 项 | 值 |
|---|---|
| 设计稿基准尺寸 | 375 × 812 px（iPhone 11 Pro / 13 mini 标准） |
| 页边距 | 16 px |
| 状态栏 | 44 px |
| 导航栏 | 44 px |
| 底部安全区 | 34 px |

### 1.2 适配规则

- 以 375 × 812 为基准设计
- 小屏（如 SE）等比缩放
- 大屏（如 14 Pro Max）保持元素尺寸不变，主区域加宽，边距与卡片可拉伸
- iPhone 刘海屏 / 灵动岛 / 底部 Home 指示器使用 iOS 安全区 API 自动避让

## 4. 按钮

### 4.1 按钮类型

| 类型 | 描述 |
|---|---|
| 主按钮 | 主操作（登录、确定、保存等），实心 |
| 次级按钮 | 次要操作，描边 1px |
| 文字按钮 | 仅文字，无边框 |

### 4.2 按钮高度

| 高度 | 字号 | 描边 | 使用场景 |
|---|---|---|---|
| 28 px | 12 px | 1 px | 列表内辅助操作 |
| 32 px | 14 px | 1 px | 卡片内操作 |
| 40 px | 16 px | 1 px | 表单常规操作 |
| 48 px | 16 px | 1 px | 主页面 CTA |

### 4.3 按钮状态

每个按钮至少包含 4 种状态：

| 状态 | 描述 |
|---|---|
| 默认 | 常规可点击状态 |
| 按下 | 用户按下时（颜色加深或透明度调整） |
| 不可点 | 视觉可见但不可交互（用 `#D1D1D1` 文字） |
| 禁用 | 与不可点同视觉，根据上下文使用 |

### 4.4 按钮组合

| 组合 | 间距 |
|---|---|
| 单按钮 | 左右页边距 16 px |
| 主 + 次（横排） | 按钮间距 11 px，左右 16 px |
| 主 + 文字（横排） | 按钮间距 16 px，左右 16 px |
| 主 + 次 + 文字（纵排） | 按钮间距 16 px |

## 7. 间距

### 7.1 间距步进

间距数值采用 **4 的倍数和 8 的倍数**：

`2 / 4 / 8 / 12 / 16 / 20 / 24 / 28 / 32 / 36 / 40 / 44 / 48 / 52 / 56 px`

### 7.2 常用间距

| 项 | 值 |
|---|---|
| 页面边距 | 16 px |
| 卡片内边距 | 12 px |
| 垂直元素间隙 | 12 px |
| 水平元素间隙 | 12 px |
| 模块间分隔 | 16 px 或 24 px |

## 9. 弹窗

### 9.1 底部弹窗（Bottom Sheet）

| 项 | 值 |
|---|---|
| 圆角 | 16 px（顶部圆角） |
| 最小高度 | 屏幕高度 40% |
| 最大高度 | 屏幕高度 80% |
| 内容超出 | 内容区滚动，操作区固定 |
| 遮罩 | `#000000` 50% 透明度 |

### 9.2 中心对话框（Dialog）

| 类型 | 说明 |
|---|---|
| 单按钮 | 仅一个"知道了"或同类操作按钮 |
| 双按钮 | 主 + 次按钮（左右排列） |
| 文字按钮 | 主 + 文字按钮 |

文案规则：
- 标题描述当前状态、信息、解决方法
- 正文文字尽可能控制在 3 行内
- 超长内容用滚动区域

## 10. 标签 Tag

### 10.1 标签样式

按颜色规范分类：主色、警告、信息、成功、错误。每种均有：
- 实心样式（背景填色 + 白色文字）
- 浅色样式（10% 透明度背景 + 主色文字）
- 描边样式（透明背景 + 描边 + 主色文字）

### 10.2 标签尺寸

| 名称 | 高度 | 字号 |
|---|---|---|
| 小 | 16 px | 10 px |
| 中 | 20 px | 12 px |
| 大 | 24 px | 12 px 或 14 px |

## 11. 轻提示 Toast

### 11.1 Toast 类型

| 类型 | 说明 |
|---|---|
| 纯文字 | 仅文字内容 |
| 带图标横向 | 图标 + 文字横向排列（成功 / 失败 / 警告） |
| 带图标竖向 | 图标 + 文字竖向排列（加载中等） |

### 11.2 Toast 规则

| 项 | 值 |
|---|---|
| 显示时长 | 默认 2 秒（短）/ 3.5 秒（长） |
| 最多行数 | 3 行 |
| 单行最大宽度 | 约 10 个汉字 |
| 显示位置 | 屏幕中部偏上（避免遮挡键盘） |

### 11.3 Toast 状态色

| 状态 | 色彩 |
|---|---|
| 成功 | 使用 `#2DC771` |
| 失败 | 使用 `#F44336` |
| 警告 | 使用 `#FF9F1C` |
| 加载 | 使用主色 `#E72737` |
