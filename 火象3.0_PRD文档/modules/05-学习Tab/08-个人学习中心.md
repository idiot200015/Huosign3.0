## 1. 模块定位

个人学习中心是用户管理自己**学习记录、订单、优惠券**的统一入口。汇总用户在学习相关的所有数据。

---

## 2. 入口与跳转

### 入口

- 学习主页顶部右侧入口（带优惠券角标）

### 出口

| 出口 | 触发条件 |
|---|---|
| [03-课程详情页](./03-课程详情页(免费课).md) | 点击免费课已学课程 |
| [06-课程播放页](./06-课程播放页.md) | 点击免费课"继续学习" |
| [07-购买与订单 → 订单详情](./07-购买与订单.md) | 点击订单卡片 |
| [07-购买与订单 → 订单列表](./07-购买与订单.md) | 点击"我的订单"完整列表 |
| 优惠券使用（跳转课程购买页）| 点击"立即使用" |

---

## 3. 页面结构

### 3.1 整体布局

| 顺序 | 区域 | 说明 |
|---|---|---|
| 1 | 顶部导航栏 | 返回 + 标题"个人学习中心" |
| 2 | 数据概览 | 学习数据简卡（已学课程数 / 已购课程数 / 优惠券数）|
| 3 | 已购课程区 | 用户购买过的付费课程列表 |
| 4 | 学习记录区 | 用户已学过的免费课程列表 |
| 5 | 我的订单区 | 用户付费订单列表（默认展示最近 3 条 + 查看全部）|
| 6 | 我的优惠券区 | 用户拥有的优惠券（默认展示最近 3 张 + 查看全部）|

### 3.2 数据概览

简卡展示：

| 数据 | 说明 |
|---|---|
| 已学课程数 | 用户开始学习过的免费课程数（无论是否学完）|
| 已购课程数 | 用户付费购买的课程数 |
| 优惠券数 | 当前持有的未使用且未过期的优惠券数 |

---

## 4. 已购课程区

### 4.1 已购课程卡片

每张卡片展示：

| 字段 | 说明 |
|---|---|
| 课程封面 | 缩略图 |
| 课程名 | 课程名称 |
| 课程类型 | 直升课 / 进阶课 / 重训课 |
| 权益状态 | "权益未使用" / "权益已使用" |
| 主按钮 | 按状态变化（详见 4.2）|

### 4.2 按钮逻辑

| 权益状态 | 主按钮 | 次按钮 |
|---|---|---|
| 权益未使用 | "去使用权益"（跳 H5）| "前往观看课程" |
| 权益已使用 | "前往观看课程" | 无 |

### 4.3 加载策略

- 默认展示最近 5 张已购课程
- "查看全部"跳转完整已购课程列表（[07-购买与订单](./07-购买与订单.md) 可继续承载，或独立页 [待对齐]）

---

## 5. 学习记录区

### 5.1 学习记录卡片

每张卡片展示：

| 字段 | 说明 |
|---|---|
| 课程封面 | 缩略图 |
| 课程名 | 课程名称 |
| 主题标签 | 6 大主题之一 |
| 学习进度 | 如 "已学 3/5 章节"、百分比进度条 |
| 主按钮 | "继续学习" / "重新学习"（已学完）|

### 5.2 加载策略

- 默认按最近学习时间倒序
- 默认展示 5 张
- "查看全部"跳转完整学习记录列表

---

## 6. 我的订单区

### 6.1 订单卡片

简化版订单卡片：

| 字段 | 说明 |
|---|---|
| 订单状态标签 | 待支付 / 已支付 / 已退款 / 退款审核中 |
| 课程名 | 简短显示 |
| 实付金额 | 如 "¥1,999" |
| 创建时间 | 简化显示（"3 天前"、"2026-04-30"）|

### 6.2 加载策略

- 默认展示最近 3 条订单
- "查看全部"跳转 [07-购买与订单 → 订单列表](./07-购买与订单.md)

---

## 7. 我的优惠券区

### 7.1 优惠券卡片

每张优惠券展示：

| 字段 | 说明 |
|---|---|
| 券面值 | 大字号显示（如 "¥500"）|
| 券名称 | 如"中级训练课程券"|
| 券类型 | 升级课程券 / 重训课程券 |
| 适用课程 | 显示可用课程类型（如"中级训练课程"）|
| 有效期 | 如 "有效期至 2026-06-30"（剩余天数 ≤ 7 天时高亮提示）|
| 状态 | 未使用 / 已使用 / 已过期 |
| 主按钮 | "立即使用"（仅未使用且未过期时显示）|

### 7.2 加载策略

- 默认按"有效期升序"展示前 3 张未使用券（即将过期的优先）
- "查看全部"跳转完整优惠券列表页

### 7.3 完整优惠券列表页

进入完整列表后：

- 顶部 Tab：未使用 / 已使用 / 已过期
- 默认 Tab：未使用
- 列表按"有效期升序"排序
- 每页加载 20 张，上拉加载更多

### 7.4 优惠券使用

用户点击"立即使用"：

- 跳转到该优惠券对应的付费课程详情页
- 详情页自动展示"该券可用"
- 用户在支付页选用该优惠券抵扣

## 9. 关键交互

### 9.1 进入页面时数据刷新

每次进入个人学习中心，自动刷新所有数据（已购、已学、订单、券）。

### 9.2 优惠券角标更新时机

学习主页右上角的"个人学习中心"入口角标显示**未使用且 7 天内即将过期**的优惠券数量。每次拉取数据后更新角标。

### 9.3 列表跳转保持

用户从某个二级页（如订单列表）返回个人学习中心，保持滚动位置和数据不刷新。

---

## 10. 异常态

| 异常 | 表现 | 处理 |
|---|---|---|
| 数据加载失败 | 部分模块为空 | 各模块独立处理，显示"加载失败，下拉刷新" |
| 网络不可用 | 全部模块加载失败 | 显示全局网络异常提示 |
| 优惠券异常状态 | 用户看到优惠券但实际不可用 | 用户尝试使用时再次校验 |

---

## 11. 接口约束

| 能力 | 说明 |
|---|---|
| 拉取学习中心聚合数据 | 推荐：单接口返回已购课程、学习记录、订单、优惠券四类数据 |
| 拉取已购课程列表 | 单独接口（用户点击"查看全部"时调用）|
| 拉取学习记录列表 | 单独接口 |
| 拉取订单列表 | 单独接口 |
| 拉取优惠券列表 | 单独接口（按状态筛选）|

接口的具体定义、字段、协议由后端开发设计，本文档仅描述业务诉求。
