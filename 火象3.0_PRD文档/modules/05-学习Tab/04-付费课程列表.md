## 1. 页面定位

付费课程列表是用户全面浏览付费课程的页面。学习主页已展示付费课程区（默认 Tab + 部分卡片），但完整查看所有付费课程时进入此列表页。

V1 付费课程分 3 类：

| 类型 | 数量 | 说明 |
|---|---|---|
| 直升课 | 5 个 | 跨等级升级账户规模 |
| 进阶课 | 4 个 | 逐级升级账户规模 |
| 重训课 | 6 个 | 解锁被锁定的实训账户 |

## 3. 页面结构

### 3.1 整体布局

| 区域 | 内容 |
|---|---|
| 顶部导航栏 | 返回 + 标题"付费课程" + 顶部 Tab |
| Tab 切换 | 直升课 / 进阶课 / 重训课 |
| 课程列表 | 当前 Tab 下的所有课程卡片 |

### 3.2 顶部导航栏

| 元素 | 内容 |
|---|---|
| 左侧 | 返回按钮 |
| 标题 | "付费课程" |
| 右侧 | 无 |

### 3.3 顶部 Tab

3 个 Tab：直升课 / 进阶课 / 重训课。

**Tab 默认展示规则**：

| 进入来源 | 默认 Tab |
|---|---|
| 学习主页"直升课"区域 → 查看更多 | 直升课 |
| 学习主页"进阶课"区域 → 查看更多 | 进阶课 |
| 学习主页"重训课"区域 → 查看更多 | 重训课 |
| 用户主动点击 Tab 切换 | 切换至选中 Tab |

### 3.4 课程卡片字段

| 字段 | 说明 |
|---|---|
| 课程封面图 | 缩略图 |
| 课程名称 | 课程标题 |
| 课程类型标签 | 如"直升 → $10,000 账户" / "进阶 → $5,000 账户" / "重训解锁" |
| 价格 | 如 "¥1,999" |
| 已购标识 | 用户已购买过的课程，卡片右上角显示"已购"标签 |
| 优惠券提示 | 如有可用优惠券，卡片显示"有优惠券可用"标签 |
| 主按钮 | "立即购买" / "已购，查看" |

### 3.5 进阶课的特殊视觉

进阶课用于"逐级升级账户规模"，按账户规模顺序展示（$2,000 → $5,000 → $10,000 → $50,000 等）。

视觉处理：

| 用户当前账户状态 | 卡片视觉 |
|---|---|
| 用户已拥有该规模 | 卡片置灰 + "已拥有"标签 |
| 用户尚未达到 | 正常展示，可购买 |
| 用户购买过但已升级 | 正常展示（课程内容永久可看，但账户权益已使用，再次购买可再次升级一次）|

> **可重复购买规则**：所有付费课均可重复购买。课程内容永久可看；账户权益是一次性的，多次升级需重复购买。

### 3.6 重训课的特殊展示

重训课仅在用户实训账户被锁定时有实际作用。

V1 处理：

- Tab 始终显示，便于用户了解
- 用户实训账户**未锁定**时，进入重训课 Tab 顶部展示提示条："你的账户当前正常运行，无需重训"
- 用户实训账户**已锁定**时，提示条显示"你的账户已锁定，可购买重训课解锁"

## 4. 列表加载

| 项 | 规则 |
|---|---|
| 默认加载 | 全部展示（直升课 5 个、进阶课 4 个、重训课 6 个，数据量小）|
| 上拉加载 | 不需要（数据量小一次加载完）|
| 下拉刷新 | 重新拉取课程列表（用于课程价格、优惠券等动态信息更新）|

---

## 5. 关键交互

### 5.1 Tab 切换动画

切换 Tab 时使用淡入淡出动画，列表内容平滑切换。Tab 滑动条跟随主色 `#E72737`。

### 5.2 已购课程的处理

| 用户状态 | 卡片表现 | 点击行为 |
|---|---|---|
| 未购 | 正常展示 + "立即购买" | 跳转 [05-付费课程详情页](./05-付费课程详情页.md) |
| 已购未升级权益 | 显示"已购，未使用"标签 | 跳转课程详情页（可重新购买或观看课程内容）|
| 已购且权益已升级 | 显示"已升级"标签 | 跳转课程详情页（看课程内容）|

---

## 6. 异常态

| 异常 | 表现 | 处理 |
|---|---|---|
| 列表加载失败 | 空白 | 显示"加载失败，下拉刷新重试" |
| 课程被下线 | 列表中不展示 | 后台数据驱动，前端无感知 |
| 价格变动 | 用户看到旧价格 | 用户进入详情页时再次校验价格，如不一致提示用户 |

---

## 7. 接口约束

| 能力 | 说明 |
|---|---|
| 拉取付费课程列表 | 按课程类型（直升 / 进阶 / 重训）返回课程列表 |
| 课程数据 | 返回卡片所需字段：封面、名称、类型、价格、已购状态、优惠券可用 |

接口的具体定义、字段、协议由后端开发设计，本文档仅描述业务诉求。
