## 1. 页面定位

首页是用户每次打开 App 后看到的默认页面，承担四项职责：

1. **品牌曝光**：通过页面标题"火象社区"和视觉风格强化品牌印象
2. **运营触达**：通过运营 banner 推广活动、课程、新功能
3. **状态汇总**：通过等级简卡、实训账户简卡让用户快速了解自身状态
4. **内容消费**：通过火象专栏让用户消费金融教育内容，提升停留时长

首页定位为"流量入口 + 内容消费"，不是核心业务页面（核心业务在训练 Tab）。

## 3. 页面结构

### 3.1 整体布局

页面采用**纵向滚动**布局，从上到下依次：

| 顺序 | 区域 | 高度（参考）|
|---|---|---|
| 1 | 顶部导航栏 | 44px |
| 2 | 运营 Banner（轮播）| 130px |
| 3 | 等级简卡 | 约 64px（2 行高）|
| 4 | 实训账户简卡 | 约 100px（3 行高，含数据展示）|
| 5 | 快捷入口 | 约 80px |
| 6 | 火象专栏标题 | 约 40px |
| 7 | 火象专栏瀑布流 | 不定（无限滚动）|

### 3.2 顶部导航栏

| 元素 | 内容 |
|---|---|
| 左侧标题 | "火象社区"（一级标题字号 18px Semibold，左对齐）|
| 右侧图标 | 消息图标（仅消息图标，无搜索 / 其他图标）|

**消息图标的角标**：

| 状态 | 显示 |
|---|---|
| 无未读消息 | 仅图标，无角标 |
| 1-99 条未读 | 图标右上角红色角标显示具体数字 |
| 99+ 条未读 | 图标右上角显示"99+" |

角标显示规则严格遵循[消息中心](../02-跨Tab通用/01-消息中心.md)模块。

### 3.3 运营 Banner

由运营在后台配置，详见 [98-02-首页 banner 配置（待输出）]。

| 项 | 规则 |
|---|---|
| 高度 | 130px |
| 宽度 | 屏幕宽度减去左右页边距（375 - 32 = 343px）|
| 圆角 | 12px |
| 数量 | 最多 5 张（运营配置）|
| 自动播放 | 4 秒切换一张 |
| 指示器 | 底部小圆点指示器，当前页主色 `#E72737`，其他页 `#D1D1D1` |
| 滑动 | 支持左右手势滑动切换 |
| 点击行为 | 跳转 banner 配置的目标（活动 / 课程 / H5 / 不跳转）|

**无 banner 配置时**：整体隐藏 banner 区域，下方内容上移。

**单张 banner**：不展示指示器，不自动轮播。

### 3.4 等级简卡

| 区域 | 内容 |
|---|---|
| 第一行 | 等级标签"Lv X · [称号]"（如 "Lv 3 · 中级交易员"）+ 右侧箭头 |
| 第二行 | XP 进度条 + 当前 XP / 下一级阈值（如 "230 / 630"）|

**视觉规则**：

- 卡片背景 `#FFFFFF`，圆角 12px
- XP 进度条主色 `#E72737`
- 字号：等级 16px Medium / 进度数字 14px DINPro
- 距离下一级 XP 用文字提示：如"距离下一级还需 400 XP"

**已达最高级（Lv 7）特殊处理**：

- 第二行显示"已达最高等级"，无进度条
- 卡片视觉可保持一致

**点击行为**：跳转等级详情页（待输出）。

**游客态**：

- 卡片显示"登录后查看你的成长"
- 点击触发[登录弹窗](../01-账号生命周期/03-登录弹窗.md)

### 3.5 实训账户简卡

| 区域 | 内容 |
|---|---|
| 标题行 | "实训账户" + 右侧箭头 |
| 数据行 | 4 个核心数据 |

**4 个核心数据**：

| 数据 | 说明 |
|---|---|
| 账户规模 | 用户实训账户的初始规模（如 "$5,000"）|
| 账户状态 | 状态标签（"运行中" / "已锁定" / "未启动"）|
| 当前净值 | 当前账户净值（如 "$5,234.56"）|
| 持仓盈亏 | 当前未平仓持仓的盈亏（如 "+$120.00" / "-$80.50"）|

**视觉规则**：

- 卡片背景 `#FFFFFF`，圆角 12px
- 数字字号 14px DINPro Medium，使用 4 列等宽布局
- 盈亏色彩：盈利 `#F44336` 红色，亏损 `#2DC771` 绿色（金融行业涨红跌绿惯例）
- 状态标签：运行中 `#2DC771` 绿，已锁定 `#FF9F1C` 橙，未启动 `#999999` 灰

**点击行为**：跳转实训账户详情页（待输出）。

**特殊场景：用户没有实训账户**

显示"领取实训账户"引导卡片：

| 区域 | 内容 |
|---|---|
| 标题 | "领取你的实训账户" |
| 描述 | "完成新手任务即可获得 $1,000 实训账户，开启实训之旅" |
| CTA 按钮 | "立即领取"（主色按钮）|

点击"立即领取"跳转账户领取流程（待输出）。

**游客态**：

- 卡片显示"登录后查看你的实训账户"
- 点击触发[登录弹窗](../01-账号生命周期/03-登录弹窗.md)

### 3.6 快捷入口

3 个图标按钮横向均分排列：

| 入口 | 图标 | 文案 | 跳转 |
|---|---|---|---|
| 训练 | 训练图标 | 训练 | 切换底部 Tab 到训练 Tab |
| 学习 | 学习图标 | 学习 | 切换底部 Tab 到学习 Tab |
| 邀请 | 邀请图标 | 邀请 | 跳转邀请中心二级页面 |

**视觉规则**：

- 卡片背景 `#FFFFFF`，圆角 12px
- 图标尺寸 32px，居中
- 图标下方文字 12px Regular，主色 `#333333`
- 3 个图标均分宽度

**注**：训练 / 学习 与底部 Tab 重复，属于"多入口冗余"设计，为提升首页快捷触达。

**游客态**：图标可见，点击触发[登录弹窗](../01-账号生命周期/03-登录弹窗.md)。

### 3.7 火象专栏区域

| 元素 | 内容 |
|---|---|
| 模块标题 | "火象专栏"（左对齐，字号 16px Semibold）|
| 标题装饰 | 标题下方的小红线（主色 `#E72737`，宽度 24px，2px 高）|
| 内容区 | 瀑布流文章卡片（详见 [02-火象专栏](./02-火象专栏.md)）|

**首屏可见**：火象专栏的前 1-2 张卡片在首屏可见，用户向下滚动看到更多。

## 4. 关键交互

### 4.1 下拉刷新

用户在首页向下拖拽到顶部以上可触发下拉刷新：

- 刷新所有数据：banner、等级、实训账户、火象专栏列表
- 刷新动画：顶部下拉指示器 + "正在刷新..." 文字
- 刷新成功：显示"刷新成功"Toast 1 秒后消失
- 刷新失败：显示"刷新失败，请检查网络"Toast

### 4.2 上拉加载更多

火象专栏支持上拉加载更多文章。详见 [02-火象专栏](./02-火象专栏.md)。

### 4.3 滚动行为

- 顶部导航栏**始终固定**（不随滚动消失）
- Banner、等级简卡、实训账户简卡、快捷入口**随页面滚动**
- 火象专栏标题在滚动到最上方时**不吸顶**（V1 不做吸顶）

### 4.4 切换 Tab 后回到首页

用户从其他 Tab 切回首页时：

- 默认保留上次的滚动位置
- 不自动刷新数据（除非用户主动下拉）
- 等级、实训账户数据使用最近一次拉取的缓存

### 4.5 数据更新触发

用户在其他模块完成动作后，回到首页时数据应同步更新：

| 触发场景 | 受影响数据 |
|---|---|
| 用户完成任务 | 等级 XP / 等级标签 |
| 用户领取实训账户 | 实训账户简卡（从"领取卡片"切换为"账户数据"）|
| 用户在外部 WebTrader 交易完成回流 | 实训账户当前净值、持仓盈亏 |
| 用户接收新消息 | 顶部消息角标 |

实现方式：返回首页时检测是否有数据更新事件，按需刷新。具体实现由前端架构决定。

## 5. 异常态

| 异常 | 表现 | 处理 |
|---|---|---|
| Banner 接口失败 | banner 不展示 | 整块隐藏，下方内容上移 |
| 等级数据接口失败 | 等级简卡数据为空 | 显示骨架屏 / "数据加载失败"占位 |
| 实训账户数据失败 | 实训账户简卡数据为空 | 显示骨架屏 / "数据加载失败"占位 |
| 火象专栏接口失败 | 列表为空 | 显示"加载失败，下拉刷新重试" |
| 网络断开 | 全部数据无法加载 | 显示全局网络异常提示 |
| 部分数据加载慢 | 各模块独立加载 | 已加载的部分先显示，加载中的部分显示骨架屏 |

## 6. 接口约束

| 能力 | 说明 |
|---|---|
| 首页聚合接口 | 返回首页所需的全部数据（推荐）：等级、实训账户、消息未读数等 |
| Banner 配置接口 | 返回当前生效的 banner 配置列表 |
| 火象专栏列表接口 | 详见 [02-火象专栏](./02-火象专栏.md) |
| 消息未读数接口 | 返回当前用户的未读消息数 |

接口的具体定义、字段、协议由后端开发设计，本文档仅描述业务诉求。

**性能要求**：

- 首屏关键数据（等级、实训账户、banner、专栏前几条）应在 1 秒内呈现
- 推荐使用首页聚合接口，减少首屏请求数

## 7. 游客态行为

游客态首页可正常浏览大部分内容：

| 元素 | 游客态行为 |
|---|---|
| 顶部消息图标 | 点击触发登录弹窗 |
| Banner | 正常展示，点击 banner 跳转目标页（如目标需登录则在落地页触发登录）|
| 等级简卡 | 显示"登录后查看你的成长"+ 登录引导 |
| 实训账户简卡 | 显示"登录后查看你的实训账户"+ 登录引导 |
| 快捷入口（训练 / 学习 / 邀请）| 图标可见，点击触发登录弹窗 |
| 火象专栏 | 正常展示，文章详情正常浏览，点赞 / 分享触发登录 |
