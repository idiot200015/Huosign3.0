## 1. 页面定位

文章详情页是用户阅读火象专栏文章正文的页面。3.0 中文章详情页为**纯阅读体验**，移除了 2.0 版本的关注 / 取关、评论、举报功能，仅保留浏览量、点赞、分享三项基础互动。

---

## 2. 入口与跳转

### 入口

| 入口 | 触发场景 |
|---|---|
| 火象专栏文章卡片 | 用户在首页点击任意文章 |
| H5 链接（外部分享）| 用户在微信 / 朋友圈点击文章分享链接，已安装 App 通过 deeplink 唤起 App 内文章详情 |
| App 内运营推送 | 运营推送中包含文章链接（V1 不主动做，预留扩展）|

### 出口

| 出口 | 触发条件 |
|---|---|
| 返回首页 | 用户点击返回按钮 |
| 系统外部 H5 | 用户点击文章中的外部链接 |

---

## 3. 页面结构

### 3.1 整体布局

| 区域 | 说明 |
|---|---|
| 顶部导航栏 | 返回按钮 + 标题"文章详情" + 右上角更多按钮（V1 暂无）|
| 作者信息区 | 头像 + 作者名 + V 标 + 发布时间 |
| 标题区 | 文章标题（大字号）|
| 正文区 | 富文本内容 |
| 底部互动区 | 浏览量 + 点赞 + 分享 |

### 3.2 顶部导航栏

| 元素 | 内容 |
|---|---|
| 左侧 | 返回按钮（图标） |
| 标题 | 文章详情（居中）|
| 右侧 | V1 不放置任何按钮 |

### 3.3 作者信息区

| 元素 | 内容 |
|---|---|
| 作者头像 | 圆形，尺寸 40px |
| 作者名称 | 14px Medium |
| V 标 | 头像右下角小标 |
| 发布时间 | 14px Regular，按"YYYY-MM-DD HH:MM"格式 |

V1 **不展示"关注 / 已关注"按钮**（移除关注功能）。

### 3.4 标题区

| 元素 | 规则 |
|---|---|
| 标题字号 | 22px Semibold（详情页突出） |
| 行高 | 32px |
| 颜色 | 一级文字 `#333333` |
| 对齐 | 左对齐 |

### 3.5 正文区

文章正文使用富文本展示，V1 支持的元素：

| 元素 | 说明 |
|---|---|
| 段落文字 | 14px Regular，行高 24px，段落间距 12px |
| 图片 | 内联图片，宽度自适应（最大宽度 = 屏幕宽度 - 32px）|
| 视频 | 内联视频，使用阿里云播放器（详见 4 节）|
| 文字链接 | 蓝色 `#3A86FF`，点击跳转 H5 |
| 加粗 | 14px Semibold |
| 列表 | 有序 / 无序列表 |
| 引用 | 左侧灰色竖线 + 缩进的引用文字 |
| 分割线 | 段落分隔 |

V1 **不支持**：

- 表格
- 代码块
- 复杂排版（如多列、悬浮元素）

### 3.6 底部互动区

固定在屏幕底部（不随滚动消失），包含：

| 元素 | 说明 |
|---|---|
| 浏览量 | 含图标"眼睛 + 数字"，仅展示，不可交互 |
| 点赞 | 含图标"点赞 + 数字"，可点击切换状态 |
| 分享 | 含图标"分享"，无数字，可点击触发分享 |

**视觉规则**：

- 高度 56px
- 背景白色 `#FFFFFF`，顶部分割线 `#E9EDF4`
- 三个元素均分宽度
- 字号 12px Regular

## 4. 视频播放（阿里云播放器）

### 4.1 视频展示

文章中嵌入的视频元素：

| 项 | 规则 |
|---|---|
| 默认状态 | 显示视频封面 + 居中"播放"按钮 |
| 宽度 | 等于正文区宽度 |
| 高度 | 16:9 比例（视频原始比例不同时按宽度等比缩放）|
| 圆角 | 8px |

### 4.2 播放交互

| 操作 | 行为 |
|---|---|
| 点击播放按钮 | 调用阿里云播放器 SDK 播放 |
| 全屏播放 | 支持全屏切换（横屏 / 竖屏）|
| 暂停 / 进度调整 | 阿里云播放器提供 |
| 退出播放 | 返回文章详情页 |
| 倍速播放 | 支持 0.75x / 1.0x / 1.25x / 1.5x / 2.0x |

### 4.3 视频技术细节

接入方式：阿里云视频点播服务（VOD）。

- 视频通过运营后台上传，转码为多码率
- App 端使用阿里云播放器 SDK 自适应码率
- 不支持下载视频
- 视频不强制看完才能继续阅读（用户可随时关闭视频继续阅读）

详细 SDK 集成 **[由开发与阿里云对接]**。

## 5. 关键交互

### 5.1 浏览量

- 用户进入文章详情页时立即触发浏览量 +1
- **不去重**（同一用户多次进入也累计）
- 异常退出（如崩溃、强杀）已计的浏览量不回滚
- 浏览量数字显示规则与列表卡片一致：< 1 万显示具体数字，≥ 1 万显示 "X 万"

### 5.2 点赞

| 状态 | 行为 |
|---|---|
| 未点赞（默认）| 灰色心形图标 + 数字 |
| 已点赞 | 红色心形图标（主色 `#E72737`）+ 数字 |
| 点击切换 | 已点赞 → 取消（数字 -1）；未点赞 → 点赞（数字 +1）|

**点赞规则**：

- 同一用户对同一文章只能点赞一次（重复点击不累加）
- 取消点赞后可以再点赞
- 点赞数实时更新到列表页

**游客态点赞**：

- 点击触发[登录弹窗](../01-账号生命周期/03-登录弹窗.md)
- 登录成功后自动完成点赞动作

### 5.3 分享

点击分享按钮触发分享底部弹窗：

| 元素 | 内容 |
|---|---|
| 弹窗形式 | 底部弹窗（Bottom Sheet）|
| 高度 | 屏幕高度 30%（仅展示分享渠道）|
| 标题 | 分享至 |
| 分享渠道 | 保存图片（如有图）/ 微信好友 / 朋友圈 / 复制链接 / 系统分享面板 |

**分享内容**：

- 分享出去的是**文章 H5 链接**（如 `https://article.huoxiang.com/{article_id}`）
- 链接打开后是文章 H5 阅读页（功能等同 App 内）
- 已安装 App 用户从 H5 点击"在 App 内查看"通过 deeplink 跳转回 App 内文章详情

**分享行为**：

- 分享不带邀请参数（与邀请系统隔离，火象专栏分享不归属邀请）
- 分享数不在 App 端展示（运营后台可看数据）

**游客态分享**：

- 点击触发[登录弹窗](../01-账号生命周期/03-登录弹窗.md)
- 登录成功后自动展示分享弹窗

## 6. 阅读体验

### 6.1 滚动行为

- 顶部导航栏始终固定
- 底部互动区始终固定
- 中间正文区随滚动

### 6.2 字号调节

V1 **不支持字号调节**。

### 6.3 收藏

V1 **不支持收藏**。

### 6.4 阅读进度记忆

V1 **不记忆**用户上次阅读位置。再次进入文章默认从顶部开始。

---

## 7. H5 文章页

通过分享链接打开文章时，H5 页面功能等同 App 内文章详情：

| 元素 | H5 行为 |
|---|---|
| 顶部导航 | 仅展示标题，无返回按钮（浏览器自带）|
| 作者信息 | 同 App 内 |
| 文章正文 | 同 App 内 |
| 视频播放 | 使用 H5 视频播放器（阿里云 H5 SDK）|
| 浏览量 / 点赞 / 分享 | 同 App 内（点赞 / 分享需引导用户登录或下载 App）|
| 底部 | "在 App 内查看"按钮，引导用户唤起 / 下载 App |

H5 页面**沿用现有方案** **[沿用 2.0]**。

## 8. 异常态

| 异常 | 表现 | 处理 |
|---|---|---|
| 文章已下线 | 接口返回不存在 | 显示"文章已下线或不存在"，提供"返回首页"按钮 |
| 网络不可用 | 文章正文加载失败 | 显示"加载失败，点击重试" |
| 视频加载失败 | 视频区域 | 显示视频封面 + "视频加载失败" |
| 视频播放失败 | 阿里云 SDK 报错 | Toast 提示"视频播放失败，请稍后重试" |
| 点赞接口失败 | 点击点赞无响应 | 撤销 UI 变化 + Toast 提示"点赞失败" |
| 分享接口失败 | 分享弹窗内 | 不影响弹窗展示，分享至外部失败由系统级提示 |
| 配图加载失败 | 图片位置 | 占位图灰色背景 |

---

## 9. 接口约束

| 能力 | 说明 |
|---|---|
| 拉取文章详情 | 根据文章 ID 拉取文章完整内容（含富文本）|
| 浏览量上报 | 用户进入详情页时上报 +1 |
| 点赞 / 取消点赞 | 接收用户操作，更新点赞状态 |
| 拉取用户点赞状态 | 文章详情接口同时返回当前用户是否已点赞 |
| 分享 | 客户端调用系统 / 微信分享 SDK，不依赖后端接口 |

接口的具体定义、字段、协议由后端开发设计，本文档仅描述业务诉求。

---

## 10. 合规要求

| 要求 | 说明 |
|---|---|
| 文章内容合规 | 由运营在后台发布前审核，App 端不审核 |
| 外部链接安全 | 文章中的外部链接如需跳转 H5，需有"即将离开火象 App"提示 [待对齐是否需要] |
| 视频版权 | 视频素材需运营确保版权合规 |
| 富文本注入防护 | 富文本数据由后端提供，前端按白名单渲染，防止 XSS |
