## 1. 模块定位

账号设置页承载用户账号相关的所有设置项：密码管理、实名认证入口、注销账号入口、退出登录。

## 4. 关键交互

### 4.1 修改密码

点击"修改密码"进入修改密码流程：

| 步骤 | 行为 |
|---|---|
| 1. 验证身份 | 用户当前绑定手机号 + 短信验证码 |
| 2. 设置新密码 | 输入新密码 + 确认密码 |
| 3. 提交 | 后端更新密码，所有 token 失效 |
| 4. 强制重新登录 | 跳转登录页（同[找回密码](../01-账号生命周期/05-找回密码.md)逻辑）|

修改密码与找回密码的区别：

| 项 | 修改密码 | 找回密码 |
|---|---|---|
| 入口 | 已登录用户在账号设置 | 未登录用户在登录弹窗 |
| 是否需要旧密码 | 否（仅短信验证码）| 否（仅短信验证码） |
| 完成后 | 强制重新登录 | 强制重新登录 |

> V1 修改密码与找回密码逻辑共用一套页面，仅入口不同。

### 4.2 实名认证

点击"实名认证"按状态跳转：

| 当前状态 | 跳转目标 |
|---|---|
| 未实名 | 实名认证流程页 |
| 审核中 | 实名结果查询页（"审核中"状态）|
| 已实名 | 实名信息查看页（脱敏展示）|
| 审核不通过 | 实名结果查询页（"审核不通过" + 重新提交入口）|

详见 [03-实名认证](./03-实名认证.md)。

### 4.3 注销账号

点击"注销账号"进入注销流程，详见 [06-账号注销](../01-账号生命周期/06-账号注销.md)。

注销前置校验：

- 进入流程时校验账户状态（进行中任务、未使用优惠券）
- 阻止注销情况显示阻止说明页

### 4.4 退出登录

点击退出登录按钮：

```
弹窗：
  标题：确认退出登录？
  正文：（无）
  按钮：取消 / 确认退出
```

确认后：

1. 清除本地 token + 用户信息缓存
2. 后端注销当前 token
3. 跳转到登录弹窗（弹起在主页面）
4. App 切换回首页 Tab，进入游客态

## 5. V1 不支持的功能

明确**不在 V1 范围**的功能：

| 功能 | 说明 |
|---|---|
| 修改 / 换绑手机号 | V1 不支持，需联系客服 |
| 第三方账号绑定（微信 / Apple / 华为）| V1 无第三方登录 |
| 登录设备管理 | V1 不展示已登录设备列表 |
| 登录历史 | V1 不展示登录历史 |
| 双因素认证 | V1 不支持 |
| 修改邮箱 | V1 无邮箱字段 |

---

## 6. 异常态

| 异常 | 表现 | 处理 |
|---|---|---|
| 退出登录接口失败 | 后端注销 token 失败 | 仍清除本地 token，跳转登录页（避免用户被卡住） |
| 实名状态加载失败 | 实名行显示"加载中" | 用户可点击进入实名页，由实名页实时校验 |
| 网络异常 | 设置项加载失败 | 显示"加载失败，下拉刷新重试" |

---

## 7. 接口约束

| 能力 | 说明 |
|---|---|
| 拉取账号设置数据 | 返回手机号、实名状态等 |
| 退出登录 | 后端注销当前 token |
| 修改密码相关接口 | 与找回密码共用 |

接口的具体定义、字段、协议由后端开发设计，本文档仅描述业务诉求。

---

## 8. 合规要求

| 要求 | 说明 |
|---|---|
| 注销路径明示 | 应用市场要求注销入口必须可达 |
| 退出登录必须支持 | 用户可随时退出当前账户 |
| 设置项的合规告知 | 涉及用户数据的修改必须有明确的二次确认 |
