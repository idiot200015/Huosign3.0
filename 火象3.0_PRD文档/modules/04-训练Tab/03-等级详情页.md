## 1. 页面定位

等级详情页是用户全面了解火象等级体系的页面：

- 完整展示 Lv1 - Lv7 等级路径
- 切换查看每个等级的权益与任务
- 引导用户感知"已经走到哪、还要走多远"

视觉为**理想化设计**：参考网易云音乐顶部 3D 椭圆轨道效果，以 7 个钻石/勋章节点环绕展示。**仅本页面使用 3D 效果**，其他页面（如训练页成长模块）使用普通进度条。

## 3. 页面结构

### 3.1 整体布局

| 区域 | 说明 |
|---|---|
| 顶部导航栏 | 返回按钮 + 标题"等级"+ 右上角"规则说明" |
| 等级路径预览区 | 3D 椭圆轨道，7 个等级节点 |
| 当前选中等级对比卡 | 当前选中等级 vs 下一级（如适用）|
| 底部任务列表区 | 当前选中等级的所有任务列表 |

### 3.2 等级路径预览区

#### 视觉设计（理想化）

- 3D 椭圆轨道，从左到右依次排列 Lv1 - Lv7 的 7 个节点
- 每个节点为一个钻石 / 勋章造型，不同等级造型差异明显（颜色 / 形状）
- 当前等级节点居中、高亮、可能有动效（如发光、轻微旋转）
- 已通过等级节点：实色（如金色），下方显示"V1"等级标签
- 当前等级节点：高亮主色，节点更大或有特殊视觉
- 未到达等级节点：灰色或半透明，下方显示等级标签

详细视觉设计 **[待 UI 提供]**，参考网易云音乐成长等级页面的顶部部分。

#### 交互

- 用户**左右滑动**切换查看不同等级
- 滑动时节点居中聚焦，下方对比卡和任务列表同步更新
- 默认进入页面时**当前等级居中聚焦**

### 3.3 当前选中等级对比卡

根据用户在路径区选中的等级，展示该等级详情：

#### 选中"已通过"等级

| 元素 | 内容 |
|---|---|
| 等级标签 | "Lv X · [称号]" |
| 状态标签 | "已通过" |
| 等级权益 | 该等级解锁的权益（具体清单 [待补充]）|
| 升级赠礼 | "已获得 X 积分赠礼"|

#### 选中"当前"等级

| 元素 | 内容 |
|---|---|
| 等级标签 | "Lv X · [称号]"（高亮）|
| 状态标签 | "当前等级" |
| XP 进度 | 当前 XP / 下一级阈值 + 进度条 |
| 邀请进度 | 邀请条件 + 当前进度 |
| 升级所需 | "升至下一级需：XP X / 邀请 Y" |
| 等级权益 | 当前等级权益 |
| 升级赠礼预告 | "升至下一级解锁 X 积分" |

#### 选中"未到达"等级

| 元素 | 内容 |
|---|---|
| 等级标签 | "Lv X · [称号]" |
| 状态标签 | "未解锁" |
| 升级条件 | 该等级升级所需的 XP 阈值 + 邀请条件 |
| 等级权益 | 该等级解锁的权益 |
| 升级赠礼 | "升至此等级解锁 X 积分" |

### 3.4 底部任务列表区

展示**当前选中等级的所有任务清单**。

#### 任务清单内容

每个等级有 3 个任务（参考任务体系文档）：
- 2 个日常任务（基于模拟账户）
- 1 个实训任务（基于实训账户）

每个任务卡展示：

| 字段 | 内容 |
|---|---|
| 任务编号 | 如 "Lv2-模01"、"Lv2-实01" |
| 任务名 | 任务名称 |
| 任务类型标签 | "日常任务" / "实训任务" |
| 奖励 | "+X XP" |
| 任务状态 | 详见 3.5 |

#### 3.5 任务状态展示规则

任务状态根据**所选等级**和**用户实际进度**动态展示：

##### 选中"已通过"等级

| 用户实际状态 | 显示状态标签 |
|---|---|
| 任务在该等级期间完成 | "成功"（绿色） |
| 任务在该等级期间失败 | "失败"（红色）|
| 任务在该等级升级时未完成 | "已失效"（灰色）|

##### 选中"当前"等级

| 用户实际状态 | 显示状态标签 |
|---|---|
| 进行中 | "进行中"（绿色）|
| 已完成 | "成功"（绿色）|
| 已失败 | "失败"（红色）|
| 已失效 | "已失效"（灰色）|
| 未开启 | "未开启"（默认）|

##### 选中"未到达"等级

所有任务统一显示 **"未解锁"**（灰色）。

#### 3.6 任务点击行为

| 任务状态 | 点击行为 |
|---|---|
| 进行中 / 成功 / 失败 / 已失效 / 未开启（当前等级）| 跳转 [04-任务详情半框](./04-任务详情半框.md) |
| 未解锁（未到达等级）| 跳转半框，但仅展示任务内容预览，无操作按钮 |
| 已通过等级的任务 | 跳转半框查看任务详情（不可重做）|

## 4. 关键交互

### 4.1 路径区切换

- 用户左右滑动 → 节点居中聚焦
- 节点切换时下方对比卡和任务列表**同步联动**
- 节点切换有过渡动效

### 4.2 默认聚焦

进入页面时默认聚焦当前等级。如果用户已达 Lv7，默认聚焦 Lv7。

### 4.3 升级赠礼积分

V1 暂不实现"点击积分跳转积分商城"功能，仅作展示。

### 4.4 规则说明

页面右上角"规则说明"链接 → 跳转规则说明页（H5 或 App 内静态页）：

| 内容 |
|---|
| 等级体系介绍 |
| 升级条件（XP 阈值 + 邀请条件双判定）|
| XP 获取规则 |
| 邀请条件说明 |
| 升级赠礼说明 |
| FAQ（常见问题）|

详细文案 **[待运营提供]**。

## 5. 异常态

| 异常 | 表现 | 处理 |
|---|---|---|
| 等级配置接口失败 | 路径区数据为空 | 显示骨架屏 / "加载失败" 重试入口 |
| 任务列表接口失败 | 任务列表为空 | 显示"加载失败" + 重试 |
| 用户邀请数据接口失败 | 邀请进度数据为空 | 显示 "0/X" 兜底 |
| 网络断开 | 整体无法加载 | 显示全局网络异常提示 |

---

## 6. 接口约束

| 能力 | 说明 |
|---|---|
| 等级体系配置 | 返回 Lv1-Lv7 各等级的：称号、XP 阈值、邀请条件、权益清单、升级赠礼配置 |
| 用户成长进度 | 返回用户当前等级、XP、邀请进度、各等级任务的实际状态 |
| 任务清单（按等级）| 返回某等级的所有任务（含任务名、编号、类型、奖励、内容描述）|

接口的具体定义、字段、协议由后端开发设计，本文档仅描述业务诉求。

---

## 7. V1 范围限制

| 不在 V1 范围 | 说明 |
|---|---|
| 升级赠礼积分 → 跳转商城 | V1 仅展示，不支持跳转 |
| 等级权益直接领取 | V1 等级权益的领取由权益本身控制（如积分自动到账），等级详情页不提供"立即领取"按钮 |
| 等级排行榜 | 不展示用户间等级排名 |
| 等级历史时间线 | 不展示用户达到各等级的时间记录 |
